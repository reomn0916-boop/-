# 画面の自動テスト

ブラウザ（Chromium）でアプリを実際に動かして確かめます。インターネットはいりません（Google ドライブはテスト用の偽物、OCR は使いません）。

```sh
cd keihi
npm install                     # playwright
npx playwright install chromium # はじめての 1 回だけ
npm test                        # 計算のテスト（数秒）
npm run test:e2e                # 画面のテスト（2〜3 分）
```

| ファイル | 確かめること |
|---|---|
| `screens.e2e.mjs` | パソコン版の全部の画面・タブ、スマホ版のタブ、使い方ガイドの検索、まとめて承認の結果ファイル |
| `soumu.e2e.mjs` | 総務の流れ: ルールを配る → 社員 2 人がスマホで提出 → 受け取り箱（ルール違反・二重申請・未提出）→ 書き換えた提出ファイルの検出 → 振込先の確認 → 全銀形式（1 行 120 桁）→ 支払済み → 結果ファイル → バックアップに受け取り箱が入る |
| `sync.e2e.mjs` | 同期フォルダ（2 台）: 削除・共通の設定・受け取り箱・自動登録が伝わり、名前は混ざらない。Google ドライブ: スマホの経費が画像つきでパソコンに出る・つなぎ直し |

`lib.mjs` は、リポジトリを配るサーバー・ブラウザの起動・偽の Google をまとめた道具です。
