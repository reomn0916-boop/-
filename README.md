# 公共工事 積算アプリ（Windows用）

奈良県・県内市町村の工事について、発注者の設計書データを取り込み、
**積算結果（工事費内訳書）と実行予算を Excel で自動で出す** ソフトです。

> いまは土台の段階です。単価・歩掛・諸経費率は**ダミーのデータ**で動作確認しています。
> 実際の入札資料（金抜き設計書のPDFとデータファイル）の見本が届いたら、取り込みと
> 内訳書の様式をそれに合わせます。

## できること

| 画面 | 内容 |
|---|---|
| 新規積算 | 設計書CSVをドラッグ（またはクリックで選択）してボタンを押すと、取り込み → 計算 → 積算結果・実行予算のExcel出力まで一度に行う |
| 明細 | **当てはめ候補**（名称・規格の似ぐあいと過去の当てはめから点数順）と「候補で一括当てはめ」、**数量計算書**（10.5×2.0×0.3 などの式）、**自社の書式で出力**。 明細ごとの歩掛・単価・金額を確認。歩掛が当たっていない行は黄色。コードを入れると**覚えて、次の工事から自動で当てる**。積算根拠メモも次の工事に引き継ぐ |
| 内訳書 | 直接工事費 → 工種 → 種別 → 細別 の階層で内訳書を表示。共通仮設費・現場管理費の積上げ分もその下に出る |
| 入札検討 | **低入札調査の資料**（入札額の内訳・明細ごとの設計/実行単価と根拠・見積一覧・手持ちの労務と機械）も出力。帯（ものさし）をクリック・ドラッグして入札額を動かせる。予定価格の見込み・調査基準価格（最低制限価格）の試算・実行原価・粗利を並べ、入札額が基準を下回る／赤字になると警告 |
| 工事の設定 | 発注者・単価の適用日・**補正（夜間・山間部など）**を設定。作成者とは別の人が「確認済」にし、提出したら**ロック** |
| スケジュール | 公告・質問締切・入札締切・開札・工期の日程と、提出物のチェックリスト。近い締切は「新規積算」に出る。開札後は落札実績へ登録 |
| 受注後 | 契約額から請負比率と**合意単価**を出し、回ごとの**出来高**と**部分払いの限度額**を計算。単価合意書・出来高内訳書を出力 |
| 質疑書 | PDF照合の食い違いや未設定の明細から質問の下書きを作り、回答も記録。Excelに出力 |
| 設計変更 | 工事を複製（または変更設計書CSVから）して「第n回変更」を作り、変更前と変更後の数量・金額の増減を対比。**スライド（物価変動）**の目安も計算 |
| 照合・答え合わせ | **金抜き設計書PDF**と数量を照合。外注していた頃の積算結果と比べ、ズレている項目を出す |
| 変更履歴 | 誰が・いつ・何を変えたか（数量の変更前の値、ロック解除の理由など） |
| 見積単価 | 業者見積を比べて採用単価（最低・平均・指定）を決め、明細や歩掛のコードとして使う。見積書ファイルも紐づけ |
| 落札実績 | 過去の落札結果を記録。落札率・自社積算の精度を出し、入札検討で予定価格の見込みを補正 |
| マスタ | **公表単価の取り込み**（Excel・CSV・PDF。縦長の単価表と、職種が横に並ぶ労務単価表に対応。取り込み前に新規・更新を確認）。年度ごとの単価・歩掛・諸経費率・補正・機械損料・単価改定を取り込む。自社単価、**発注者ごとの設定**（最低制限価格の式・内訳書の深さ・電子入札CSVの文字コード） |
| 設定 | データファイルの場所（**社内の共有フォルダ**に置いて共有）、担当者名、**利用者と権限**（管理者／確認／積算／閲覧）、**バックアップ**（起動時に1日1回自動・30個保存・点検・復元） |

出力：積算結果（総括・工事費内訳書・明細・単価表）、実行予算、電子入札用内訳書CSV、変更対比表（変更のとき）

## 計算の流れ

1. 単価の出し方は3通り
   - 積上げ：歩掛（労務・機械・材料の数量）× 年度・地区の単価（歩掛の入れ子も可）
   - 施工パッケージ：東京地区の標準単価 × { Σ 構成比 ×（当地の単価 ÷ 東京の基準単価）+ 補正しない分 }
   - 単価そのまま：市場単価・見積単価など
   - 機械は、単価表になければ機械損料から「損料×時間＋燃料×時間×燃料単価＋運転手」で運転1日あたりを作る
   - 補正（割増）：工事全体または行ごとの条件で、労務・機械・材料・全体・諸経費率に係数を掛ける
   - 単価の適用日を入れると、単価改定.csv の新しい単価に切り替わる
2. 単価 × 数量 → 明細の金額 → 合計して **直接工事費**
3. 共通仮設費・現場管理費・一般管理費等を **年度ごとの率の式** で計算し、積上げ分（区分＝共通仮設／現場管理の明細）を足す。区分「直接（率対象外）」の行（処分費・支給品など）は率の対象額から除く → **工事価格**（端数単位で調整）→ 消費税
4. 調査基準価格・最低制限価格の試算：直接工事費×0.97 ＋ 共通仮設費×0.90 ＋ 現場管理費×0.90 ＋ 一般管理費等×0.68 を、工事価格の75〜92%の範囲に収める（中央公契連モデル型。**係数は発注者ごとの設定で変える**）
5. 実行予算は、自社単価があればそちらを優先して同じ計算をし、設計との差を出す

計算ルール（端数処理・率の式・消費税率）はプログラムに書き込まず、年度ごとの表で持ちます。
基準が変わったら、新しい年度のフォルダを作って取り込むだけです。

## 年度マスタの形式（`マスタ/R8/` のように年度ごとのフォルダ）

| ファイル | 列 |
|---|---|
| 単価.csv | 種類（労務/材料/機械/市場単価）, コード, 名称, 規格, 単位, 単価, 地区（空欄=共通） |
| 歩掛.csv | コード, 名称, 規格, 単位, 基準数量, 諸雑費率 |
| 歩掛構成.csv | 歩掛コード, 種類（上記＋歩掛）, 資源コード, 数量 |
| 諸経費.csv | 工種区分, 費目（共通仮設費/現場管理費/一般管理費等）, 式（power: A×P^b / log: A×log10(P)+b）, A, b, P下限, P上限 |
| ルール.csv | 項目, 値（単価の有効桁数, 単価の端数処理, 率の小数桁, 工事価格の端数単位, 消費税率, 基準価格_直接工事費 などの係数, 基準価格_下限, 基準価格_上限） |
| 施工パッケージ.csv | コード, 名称, 規格, 単位, 標準単価（東京地区） |
| 施工パッケージ構成.csv | パッケージコード, 種類, 資源コード, 構成比, 基準単価（東京地区） |
| 補正.csv | コード, 名称, 対象（労務/機械/材料/市場単価/全体/共通仮設費率/現場管理費率）, 係数, 歩掛コード（空欄=全部） |
| 機械損料.csv | コード, 名称, 規格, 運転時間, 損料_1時間, 燃料_1時間, 燃料コード, 運転手コード, 運転手人数, 諸雑費率 |
| 単価改定.csv | 種類, コード, 地区, 適用日（YYYY-MM-DD）, 単価 |

ほかに、発注者ごとの設定（発注者, 項目, 値）と落札実績（日付, 発注者, 工事名, 工種区分, 予定価格, 基準価格, 落札額, 落札者, 自社入札額, 自社積算額, 備考）もCSVで取り込めます。

設計書CSVに「区分」列（直接／直接（率対象外）／共通仮設／現場管理）や「補正」列があれば、それも読み込みます。

見本は `sample/` にあります（中身はすべてダミー）。

## 使い方

### Windowsで使う
GitHub の「Actions」→「Windows版をビルド」→ 最新の実行 → `積算アプリ-windows` をダウンロードし、
展開した中の `積算アプリ.exe` を起動します。

### 開発用（Python）
```
pip install -r requirements.txt pytest
python -m pytest            # テスト
python -m sekisan           # 画面を開く
python -m sekisan master R8 sample/master/R8
python -m sekisan run sample/設計書.csv --name 試し --fy R8 --work-type 道路改良（ダミー） --out 出力
```
