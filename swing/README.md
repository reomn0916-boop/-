# スイングボード

スイングトレード（数日〜数週間の売買）向けに、**相場の地合い・材料ニュース・注目銘柄**を毎日まとめるスマホ用 Web アプリです。ホーム画面に追加するとアプリとして使えます。

公開後の URL：GitHub Pages の URL の末尾に `/swing/` をつけたもの。

## 画面

| タブ | 内容 |
|---|---|
| 今日 | 地合い（追い風／中立／向かい風）、日経平均・TOPIX・米国株・SOX・ドル円・VIX・米金利、話題のテーマと影響を受ける業種、**今日の注目銘柄**（点数・買い目安・利確目安・損切り）、材料ニュース |
| 銘柄 | 全銘柄を型（押し目／高値ブレイク／売られすぎ反発／上昇トレンド）・業種で絞り込み、点数・前日比・出来高などで並べ替え |
| ニュース | プラス／マイナス／銘柄の材料／テーマ／ウォッチ銘柄で絞り込み。見出しを押すと記事へ |
| 成績 | **これまでの注目銘柄のその後**（翌日の寄りで買い、目安どおり売ったとしての勝率・平均損益）と、**過去2年のルールの検証**（型別・点数帯別、「いつ買っても同じ」との比較） |
| 保有 | 買った銘柄を登録すると、損切りライン割れ・利確到達・「損切りを買値に上げる」タイミング・売りのサイン（25日線割れ、MACD 下抜けなど）・保有期間の長さを知らせる。ウォッチ銘柄、設定 |

今日の画面には、ほかに **業種の強さランキング**、保有銘柄のお知らせ、新しく注目に入った銘柄の「新」マークも出ます。

銘柄を押すと、ローソク足チャート（25日線・75日線・出来高・利確/損切りの線）、売買の目安、**買える株数**（資金 × 許容損失% ÷ 損切り幅、100株単位）、注目する理由・注意点、**翌日の見送りライン**（これより高く寄ったら追わない）と押し目の指値案、**この銘柄での過去の成績**、関連ニュース、Yahoo!ファイナンス・株探へのリンクが出ます。

## しくみ

```
GitHub Actions（平日 7:07 と 16:37）
  └ swing/scripts/update.py … 株価（Yahoo! Finance の日足）と RSS ニュース（NHK・Yahoo!ニュース・Google ニュース・適時開示）を集める
      ├ 同じルールで過去2年を検証（バックテスト）
      ├ 注目銘柄を data/history.json に記録し、その後の成績を毎回計算
      └ swing/data/latest.json・charts.json に書き出してコミット
スマホのアプリ（swing/index.html）… その JSON を読んで表示するだけ
```

- サーバー・API キー・費用は不要です（Python の標準ライブラリだけで動きます）。
- 最初は **サンプルデータ** が入っています（画面上部に黄色の帯が出ます）。

## 使い始める

1. この変更を既定のブランチ（main）に取り込む。
2. リポジトリの **Actions** タブ → 「スイングデータ更新」 → **Run workflow** を押す（数分で終わります）。
   - 以後は平日に自動で動きます。
   - Settings → Actions → General → Workflow permissions が「Read and write」になっていないと保存に失敗します。
3. `https://<GitHub Pages の URL>/swing/` をスマホで開き、共有メニューから **ホーム画面に追加**。

手元で試すとき：

```sh
python3 swing/scripts/update.py          # 本物のデータ（ネットが必要）
python3 swing/scripts/update.py --demo   # サンプルデータ
cd swing && python3 -m http.server 8000  # http://localhost:8000 で表示
```

## 点数のつけ方（0〜100 点）

50 点を基準に足し引きします。型（押し目・高値ブレイク・売られすぎ反発）に当てはまり基準点以上の銘柄を「今日の注目銘柄」にします。基準は地合いで変わります（追い風・やや追い風：60点・10銘柄／中立：63点・8銘柄／向かい風：68点・5銘柄）。地合いは日経平均・S&P500・VIX と、対象銘柄のうち25日線の上にある割合から決めます。

| 型 | 条件 |
|---|---|
| 押し目 | 25日線・75日線が上向きの上昇トレンド中、25日線から −3%〜+2.5%、RSI 35〜58 |
| 高値ブレイク | 20日高値を出来高 1.3 倍以上で上抜け（RSI 80 未満） |
| 売られすぎ反発 | RSI 32 未満、25日線から −7% 以上、当日陽線（逆張り） |
| 上昇トレンド | 上の型ではないが上昇トレンド |

- 加点：MACD の上抜け、日経平均より強い（20日）、出来高を伴う上昇、プラスの材料ニュース（上方修正・増配・自社株買いなど）、追い風テーマの業種（例：円安 → 自動車・電機）
- 減点：下降トレンド、RSI 75 超、25日線から +12% 超、売買代金 10 億円/日 未満、マイナスの材料
- 損切り：値動きの大きさ（ATR）と型から決める。利確：損切り幅の 2 倍（押し目は直近高値も考慮）

## 成績・検証の計算方法

- シグナルの翌営業日の**寄り付きで買う**。寄りで損切りより下・利確より上なら見送り
- 損切り・利確に届いたらそこで売る（寄りで飛び越えたら寄り値）。同じ日に両方届いたら**損切り扱い**（厳しめ）
- 最長 15 営業日で手じまい。手数料・税金は含まない。検証はニュースを使わずテクニカルの点数だけ
- 記録を始める前の 20 営業日分は、同じルールで過去の日に選んだ銘柄を再現して表示します
- 計算のテスト：`python3 -m unittest discover -s swing/tests`

## カスタマイズ

- 対象銘柄：`scripts/universe.json`（コード・名前・業種・ニュース用の別名）
- ニュースの言葉・テーマと業種の対応：`scripts/update.py` の `POS_WORDS`・`NEG_WORDS`・`THEMES`
- 更新時刻：`.github/workflows/swing-update.yml` の `cron`（UTC）

## 注意

点数・売買の目安は、株価の動きとニュースの**見出し**から機械的に計算したものです。売買をすすめるものではありません。決算発表日・権利確定日・本文の内容はご自身で確認し、投資は自己責任で行ってください。データの取得元の仕様が変わると取得できなくなることがあります（Actions のログに「!」で表示されます）。
