# 現場CAD

スマホのブラウザで動く、現場向けの簡易 CAD です。図面の寸法・面積をその場で確認でき、GPS で現在地を **平面直角座標（X・Y）** に変換して記録できます。インストール不要で、ホーム画面に追加するとオフラインでも使えます。

事務所で使う **パソコン版**（`pc/`）もあります。リボン・マルチボックス・プロパティ・レイヤの土木 CAD の画面で作図・編集・横断図・縦断図・測量計算・印刷ができ、スマホ版とは **.gcad ファイル** でデータを行き来できます（[パソコン版](#パソコン版)）。

> **ラク経費**（`keihi/`）: レシートを撮るだけの経費精算アプリも同じリポジトリにあります。金額・日付・お店・科目・登録番号を自動で読み取り、月末は精算書 PDF（領収書の台紙つき）をワンタップで作って送れます。公開後は `https://…/keihi/`（スマホ）・`https://…/keihi/pc/`（パソコン）を開きます。詳しくは [keihi/README.md](keihi/README.md)。

## できること

### 図面・計測
| 機能 | 内容 |
|---|---|
| 作図 | 点・線（連続）・円。タップで配置し、端点・中点・**交点**・線上・円周上に自動スナップ |
| 座標入力 | `X,Y`（絶対）／`@ΔX,ΔY`（相対）／`@距離<方向角`（角度は `45-30-15` のような度分秒も可） |
| 計測 | 距離（水平距離・方向角・ΔX/ΔY）、3点のなす角、面積（㎡・坪）・周長 |
| 情報表示 | 図形をタップで長さ・座標・緯度経度・**測点**。端点や頂点をまとめて点登録 |
| 画層 | DXF の画層ごとに表示／非表示（非表示の画層はスナップ・選択の対象外） |

### 現場での位置出し → 逃げ → SIMA
1. **図面を読み込む**（DXF）。基準点・境界杭の座標は SIMA/CSV で読み込む（種別「基準点」になる）。
2. 図面の縮尺が違う（mm で描かれた DXF など）ときは **図面の縮尺を合わせる**（メニュー）：寸法の両端の2点か寸法線を選び、正しい長さを入れる（寸法値や「5,000」などの数字の文字を選ぶと値が入る）。1点目は動かず、基準点と GPS の点も動かない。
3. **図面を現場の座標に合わせる**（メニュー）：図面上の点と現場の点（座標既知の点・GPS）を 1 組（移動）〜 2 組（移動＋回転、縮尺は任意）指定。2点間の距離の差（mm）を確認してから適用。基準点と GPS の点は動かない。元に戻す可。
4. **位置出し点**：「点」ツールで図面の角・交点をタップ（種別・頭文字を指定可）。図形を選んで「頂点を点登録」でも可。
5. **逃げ杭**：「逃げ」ツール
   - 角・交点：つながる各辺の延長上に逃げ
   - 線の延長：線の両端の先に逃げ
   - 平行：線・図形をタップ → 逃げる側をタップ。外周を外側／内側へ平行に逃がす（角は留め）
   - 距離は `1` や `1,2`（2本ずつ）。点名は元の点名＋番号（例: K1-1, K1-2）。逃げ線は「逃げ」画層に点線で描く
   - 図形を選んで「全部の角に逃げ」で一括作成
6. **SIMA で書き出す・送る**：種別（基準点／位置出し／逃げ／その他）を選んで出力。**Shift_JIS** で書き出すので TS や国内の CAD でも文字化けしない。閉じた図形を区画（画地）として出力も可。スマホの共有メニューからメール・LINE 等で直接送れる。

点の種別は図面上で記号と色が変わります（基準点 ▲ 青・位置出し ✛・逃げ ⊗ 橙）。座標一覧は種別で絞り込めます。杭打ち計算の対象に「逃げ」「位置出し」など種別名を書くと、その種別の点を一括で計算します。

### 施工図をかいて出力する
| 機能 | 内容 |
|---|---|
| 寸法 | 始点 → 終点 → 寸法線を置く位置をタップ（離れは数値入力も可）。補助線・斜線付き。単位は m（0.000）/ mm（1,000）を切替 |
| 文字・引出線 | 文字は置く位置をタップして入力。大きさは印刷時の高さ（2.5〜7 mm）で指定。引出線・円は「線」ボタン、角度は「距離」ボタンの中で切替 |
| 範囲 | 今の画面／2点で指定／選択した図形／全体 |
| 用紙・縮尺 | A4〜A1・縦横。縮尺は自動（1/50・1/100 など標準から）または指定。図の回転（選択した線を縦に合わせる）にも対応 |
| 図面の内容 | 図面枠、表題欄（工事名・図面名・縮尺・作成日・作成者・座標系）、範囲内の点の座標表（種別で色分け・凡例付き）、方位記号、スケールバー、座標グリッド（任意） |
| 出力 | **PDF**（アプリ内で生成するのでスマホでも保存・共有できる）、**画像（PNG）**、**印刷**、**DXF**（範囲内の図形＋図枠・表題欄・座標表を縮尺に合わせて出力。文字は図の回転に合わせた向き） |

画面上部の「施工図」ボタンで、表示中の範囲から施工図を作ります。

### 計算（∑ ボタン）
| 区分 | 計算 |
|---|---|
| 座標計算 | 逆計算（2点間）／放射計算／杭打ち計算（TS の夾角・距離の一覧）／交点計算／距離交会（引照点から杭の復元）／垂線計算（追加距離・幅）／幅杭・オフセット点 |
| 面積 | 座標求積表（座標法・倍面積・坪） |
| 路線 | 路線計算（IP 法・単曲線）で中心杭・主要点（BC/MC/EC）・幅杭の座標／測点⇔座標の変換／単曲線の要素（TL・CL・SL・M・C） |
| その他 | 勾配・法長 |

- 点は **点名・`X,Y`・`GPS`（現在地）** で指定でき、📍 で図面上の点をタップして拾えます。
- 結果はそのまま **点登録・図で確認・計算書に追加** ができます。
- **計算書** は溜めておいて、印刷（PDF 保存）や CSV に出力できます。
- 路線を図に追加すると、点を選んだときや GPS の現在地に **測点（例: No.3+12.35 右 2.40 m）** が表示されます。

### GPS
| 機能 | 内容 |
|---|---|
| 現在地 | 緯度経度を平面直角座標（1〜19系）へ変換。10回平均で点を登録 |
| 誘導 | 選んだ点までの距離・方向（杭探し用）、路線上の測点・幅 |
| 基準点補正 | 座標が分かっている点に立って GPS を取り、現場の座標に合わせる（1点: 平行移動、2点以上: 回転も、3点以上: 縮尺も）。任意座標の現場でも使える |

### データ
| 機能 | 内容 |
|---|---|
| 読み込み | DXF（LINE / LWPOLYLINE / POLYLINE / POINT / CIRCLE / ARC / TEXT / MTEXT / 長さの DIMENSION、文字の回転・配置。Shift_JIS・UTF-8 を自動判別し、`\U+` 形式の日本語、`%%c`（φ）・`%%d`（°）・`%%p`（±）なども戻す）、SIMA、CSV |
| 書き出し | DXF（R12・Shift_JIS・画層の色と線種。寸法線・引出線・ハッチ・路線は線・円弧・文字に展開）、SIMA（Shift_JIS・区画も可）、CSV（Excel 用 BOM 付き）、プロジェクト（.gcad） |
| 保存 | 端末内（localStorage）に自動保存。元に戻す対応 |

座標の向きは測量と同じく **X＝北、Y＝東**、方向角は北から時計回りです。DXF では DXF の X＝東、Y＝北として読み書きします。

## パソコン版

`pc/index.html`（公開後は `https://…/pc/`）を Chrome か Edge で開きます。アドレスバーの［インストール］でアプリとして使えます（オフライン対応・.gcad ファイルを開ける）。

### 画面と操作
| 部分 | 内容 |
|---|---|
| リボン | ファイル／ホーム／作図／図形編集／土木／測量計算／現場連携／表示 のタブ |
| スタイルバー | 現在のレイヤ・色・線種・線幅・文字高、縮尺（1:N）・用紙、入力単位（m / mm）、寸法の表示単位。図形を選んでいるときは選んだ図形に反映 |
| マルチボックス（左） | 実行中のコマンドの指示・設定（半径・間隔・端末記号など）・座標や数値の入力欄・確定／1つ戻る／終了 |
| プロパティ（右） | 選んだ図形の座標・長さ・半径・文字・寸法値・ハッチなどを直接変更。複数選択では色・線種・線幅・レイヤを一括変更 |
| レイヤ（右） | 表示切替・現在レイヤ・色・線種・線幅。右クリックでこのレイヤだけ表示・図形の選択・名前変更 |
| 図面 | 白い紙が用紙枠（印刷範囲）。図面枠・表題欄・方位・スケールバーも表示 |
| ステータスバー | 座標（X・Y）、点スナップ（点・端点・中点・交点・中心・垂点・線上）、直交（F8）、グリッド |

- 画面: 上の段に保存・元に戻す・やり直し・印刷のボタンと「コマンドを検索」（Ctrl+K）。よく使うコマンドは大きいボタン、ほかは小さいボタンで並べ、ボタンに名前・説明・キーのヒントが出ます。リボンは Ctrl+F1 でたためます。明るい / 暗い表示を切り替えられます。
- 図面が空のときはスタート画面（白紙・開く・スマホのデータ・練習用の図面）。選んだ図形は四角いつまみをドラッグして形を直せます。作図中は長さ・方向角、点の指示中は座標を、カーソルの横に表示します。
- マウス: 左クリックで点・選択、ドラッグで範囲選択（左→右は囲んだ図形、右→左はかかった図形）、右クリックでメニュー、ホイールで拡大縮小、中ボタンドラッグで移動。
- キー入力: `X,Y`・`@ΔX,ΔY`・`@距離<方向角`・長さ（カーソルの方向へ）・点名。Enter で確定・直前のコマンド、Esc で終了、Backspace で 1 つ戻る、Ctrl+Z/Y/C/X/V/S/O/P。

### できること
| タブ | コマンド |
|---|---|
| 作図 | 単線・連続線・矩形・平行線・円・3点円・円弧・3点円弧・点（測点）・等分点・文字・引出線・寸法（平行・水平・垂直・直列・半径・角度）・ハッチング・求積図形・方位記号 |
| 図形編集 | 移動・複写・回転・反転・拡大縮小・**縮尺合わせ**・配列複写・削除・伸縮・部分消去・角作成・面取り・R面取り・分割・結合・分解・計測（距離・角度・面積・座標） |
| 土木 | 座標一覧（表で編集）・頂点を点登録・座標合わせ（CAD 座標の図面を基準点に合わせる、残差表示）・**横断図**（現況と標準断面から計画線・切土／盛土面積・ハッチ・数値表）・**縦断図**（測点・地盤高・計画高・VIP と縦断曲線・切盛高・勾配欄）・求積表・逃げ杭・杭打ち表 |
| 測量計算 | スマホ版と同じ計算（逆計算・放射・杭打ち・交点・距離交会・垂線・幅杭・座標求積・路線・測点⇔座標・曲線要素・勾配）。計算書の印刷・CSV |
| ファイル | .gcad の新規・開く・上書き保存、DXF・SIMA・CSV の読み込み（ドラッグ＆ドロップ可）と書き出し、画像、**印刷・PDF**（図面枠・表題欄・座標表付き、200〜400 dpi） |

DXF は画層の色・線種（実線・破線・点線・一点鎖線・二点鎖線）・図形ごとの色も読み書きします。長さの寸法（DIMENSION）も寸法線として読み込みます。

**縮尺合わせ**（図形編集・土木タブ）: 縮尺の違う図面や mm 単位の DXF を正しい大きさにします。
- 2点と実寸: 長さの分かっている2点を指示し、正しい長さを入力（1点目は動かない）
- 寸法線: 寸法線・線をクリックして正しい長さを入力（書き換えた寸法値や、数値の文字を選ぶとその値を使う）
- 座標: 図面上の点をクリック → 正しい座標（点名か X,Y）を入力を2組以上。縮尺と回転・位置をまとめて合わせ、ずれ（mm）を表示

### スマホ版との連動
1. パソコン版［現場連携］→［現場へ送る］で `.gcad` を保存し、LINE・メール・Google ドライブなどでスマホへ送る。
2. スマホ版のメニュー［パソコン連携］→［パソコンから受け取る］で開く。
3. 現場で位置出し点・逃げ杭・GPS の点を作ったら、スマホ版［パソコンへ送る］で `.gcad` を共有。
4. パソコン版［現場データ取込］で **差分だけ** 取り込む。どちらで作った図形も残り、同じ図形を両方で変えたときは新しい方が残ります。削除も反映されます。同じ点名で位置が違う点は名前を変えて取り込みます。

［連携フォルダ］に Google ドライブ・OneDrive などの同期フォルダを指定すると、［現場へ送る］で直接保存でき、スマホから同じフォルダに保存したファイルを「新しいデータがあります」と知らせます（Chrome・Edge）。データはサーバーには送らず、ファイルのやりとりだけで連動します。

## 使い方（公開方法）

詳しい導入手順（公開・スマホとパソコンへの入れ方・初期設定・動作確認のチェック表）は `manual/現場CAD_導入手順.pdf` を見てください。説明書（`manual/現場CAD_はじめてガイド.pdf`・`manual/現場CAD_操作リファレンス.pdf`）と練習問題集（`manual/現場CAD_練習問題集.pdf`、練習データは `manual/練習データ/`）も同じフォルダにあります。

GPS（位置情報）は **https** でしか使えないため、GitHub Pages などで公開して使います。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を「Deploy from a branch」、ブランチとフォルダ（`/ (root)`）を選んで保存
3. 表示された URL をスマホで開き、共有メニューから **ホーム画面に追加**

PC で試すだけなら、このフォルダで `python3 -m http.server` を実行して `http://localhost:8000`（スマホ版）・`http://localhost:8000/pc/`（パソコン版）を開きます（localhost では GPS も動作します）。

## 精度について

- 座標変換は国土地理院の計算式（JGD2011 / GRS80）で、mm 以下の精度です。
- ただしスマホの GPS 自体の精度は数 m 程度です。境界や杭打ちなど精度が必要な作業は、測量機器で確認してください。
- 表示される距離は平面直角座標上の距離（縮尺係数を補正しない値）です。
- 路線計算は単曲線（円曲線）のみ対応です。緩和曲線（クロソイド）は未対応です。
