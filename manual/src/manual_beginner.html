このアプリでできること

図面を見て測る現場で図面を開いて、長さ・面積・座標をその場で確かめる
杭の位置を出す建物の角などの座標を出し、逃げ杭も作って測量機に送る
図面をかいて印刷パソコンで図面・横断図・縦断図をかき、PDF や紙にする

データはインターネット上には送りません。スマホやパソコンの中に保存されます。

まず覚える言葉

わからない言葉が出てきたら、ここに戻ってきてください。

座標（ざひょう）
場所を数字で表したもの。このアプリでは X が北向き、Y が東向き（測量のきまり）。学校の数学とは X と Y が逆なので注意。
基準点
座標がはっきり分かっている点。測量会社からもらう「座標の一覧」に載っている点です。図面に▲（青）で表示します。
位置出し
図面にかいてある建物の角などを、実際の地面に印をつけること。その点を図面に ✛ で表示します。
逃げ杭（にげぐい）
工事で本当の杭が抜けても位置を戻せるように、少し離れた場所に打つ控えの杭。図面に ⊗（橙）で表示します。
TS（トータルステーション）
現場で使う測量機。このアプリで作った点を送ると、その場所を案内してくれます。
DXF（ディーエックスエフ）
図面のファイルの形式。ほかの CAD ソフトとやりとりするときに使います。
SIMA（シーマ）
点の座標のファイルの形式。TS や測量ソフトに点を送るときに使います。
.gcad（ジーキャド）
このアプリ専用のファイル。スマホとパソコンの間で、図面や点をまるごとやりとりします。
縮尺
図面を紙に印刷するときの縮め方。1:100 なら、紙の 1 cm が実際の 1 m。

スマホとパソコンに入れる

アプリはインターネットのページとして公開されます。担当の人から アプリのアドレス を教えてもらってください。パソコン版は、そのアドレスの最後に pc/ を付けたものです。

iPhone

  1. Safari でアプリのアドレスを開く。
  2. 下の 共有（四角から矢印が出たマーク）を押す。
  3. ホーム画面に追加 を押す。これでアプリのように開けます。電波がない場所でも使えます。

Android

  1. Chrome でアプリのアドレスを開く。
  2. 右上の ⋮ から ホーム画面に追加（または「アプリをインストール」）を押す。

パソコン（Windows）

  1. Chrome か Edge で、パソコン版のアドレス（最後が pc/）を開く。
  2. アドレス欄の右の インストール マークを押す。スタートメニューから開けるようになります。
はじめに一度だけ: 位置情報の許可GPS を使うとき「位置情報の使用を許可しますか」と聞かれます。許可 を選んでください。

スマホの画面の見かた

最初の画面まだ何も入っていないときは、図面の上に「図面を読み込む」「座標を読み込む」「パソコンから受け取る」「白紙でかく」の4つのボタンが出ます。ここから始めるのがいちばん簡単です。
まちがえたら右下の 戻す を押すと、ひとつ前に戻ります。何度でも戻せます。

図面を開いて長さを測る

  1. 最初の画面の 図面を読み込む（または左上の ☰ → 図面を読み込む（DXF））を押し、もらった DXF ファイルを選ぶ。
  2. 図面が出たら、指で広げて見たい所を大きくする。
  3. 下の 距離 を押し、測りたい2か所を順にタップ。長さが出ます。線の端や角に近い所をタップすると、ぴったりその点に吸い付きます。
  4. 面積を知りたいときは 面積 を押して、角を順にタップ。
図面がとても大きく（または小さく）見えるとき図面が mm で作られていると、1000 倍の大きさで入ってくることがあります。☰ → 図面の縮尺を合わせる を開き、寸法線を選ぶ で図面の寸法をタップして 合わせる。寸法の数字が自動で入ります。

位置出しと逃げ杭を作る

図面の建物の角などを現場に出すための点と、その控えの逃げ杭を作ります。

  1. 基準点を入れる: 最初の画面の 座標を読み込む か ☰ → 座標を読み込む（SIMA / CSV） で、測量会社からもらった座標のファイルを選ぶ。▲ の点が出ます。
  2. 図面の位置を合わせる: 図面の座標が現場と違うときは ☰ → 図面を現場の座標に合わせる。図面の上の点と、それに当たる基準点を2組選んで 確認 → 合わせる。ずれが mm で出るので、大きすぎないか見ます。
  3. 位置出し点を置く: 下の 点 を押し、建物の角をタップ。P1、P2… と名前が付きます。
  4. 逃げ杭を作る: 下の 逃げ を押す。距離に 1（1 m 離す）と入れて、角をタップ。線の延長の上に ⊗ の逃げ杭ができます。名前は「P1-1」のように元の点の名前に番号が付きます。
2本ずつ作りたいとき距離に 1,2 と入れると、1 m と 2 m の2本ずつ作れます。

TS（測量機）に送る

  1. ☰ → SIMA で書き出す・送る。
  2. 送る点の種類（位置出し・逃げなど）にチェックを付ける。
  3. 保存 か 共有 で、メールや LINE で TS 担当の人やパソコンに送る。

文字は国内の測量機で読める形（Shift_JIS）で書き出すので、点の名前が化けません。

スマホとパソコンでやりとり

パソコン → スマホ

  1. パソコン版の 現場連携 タブ → 現場へ送る → ファイルに保存。
  2. できた .gcad を LINE やメールでスマホに送る。
  3. スマホ版の ☰ → パソコンから受け取る で、そのファイルを選ぶ。

スマホ → パソコン（現場で作った点を戻す）

  1. スマホ版の ☰ → パソコンへ送る（.gcad） で、LINE やメールでパソコンに送る。
  2. パソコン版の 現場連携 タブ → 現場データ取込 でそのファイルを選び、取り込む（差分）。
「取り込む（差分）」なら消えません両方で作った点や線はどちらも残ります。同じものを両方で直したときは、あとで直した方が残ります。「開く（置き換え）」を選ぶと今の図面がまるごと入れ替わるので注意。

パソコン版の基本

最初の画面図面が空のときは「白紙からかく」「ファイルを開く」「スマホのデータを取り込む」「練習用の図面を開く」のボタンが出ます。

線を1本引いてみる

  1. 上の 作図 タブ → 単線 を押す。
  2. 図面の上で、始まりの場所をクリック、終わりの場所をクリック。線が引けます。
  3. 長さを決めたいときは、始まりをクリックしたあと、キーボードで 5 と打って Enter。マウスの向きに 5 m の線が引けます。
  4. 終わるときは Esc。

形を直す（つまみ）

  1. 直したい線や図形をクリックして選ぶ。角に小さな四角い「つまみ」が出ます。
  2. つまみをドラッグして、新しい場所で離す。その角だけが動きます。線のまん中のつまみは線ごと、円の右のつまみは大きさが変わります。
  3. まちがえたら Ctrl + Z。

困ったとき

図面が見えなくなった・どこにあるか分からない

スマホは右下の四角いボタン（全体表示）、パソコンは Home キー（または マウスの中ボタンを2回）で、全体が見える大きさに戻ります。

まちがえて消してしまった

スマホは 戻す、パソコンは Ctrl + Z。何回か押すと、もっと前に戻ります。

図面の大きさがおかしい（1000 倍など）

図面の縮尺を合わせる（パソコンは 図形編集 タブの 縮尺合わせ）で、寸法を1か所選ぶと直ります。

文字が「%%c300」のように変になる

今のアプリでは φ300 のように直して読み込みます。それでも変な文字があれば、その DXF を担当の人に見せてください。

GPS の位置がずれる

スマホの GPS は数 m ずれることがあります。杭打ちなど正確さが必要な作業は、必ず TS などの測量機で確かめてください。GPS は「だいたいの場所を知る」ために使います。

別のスマホやパソコンでデータが見えない

データはその機械の中にだけ保存されます。別の機械で使うときは .gcad ファイルで送ってください（やりとりの方法）。スマホの「Safari の履歴を消す」などをするとデータが消えることがあるので、大事な図面は .gcad で保存しておきましょう。

スマホ版の「使い方」はどこ？

☰ メニューのいちばん下の 使い方 です。最初の画面の「使い方を見る」からも開けます。

パソコン版でボタンを押しても何も起きない

何かの作業の途中かもしれません。Esc を押して終わらせてから、もう一度押してください。左のマルチボックスに今の作業の説明が出ています。
