# ラク経費

**レシートを撮るだけ**の経費精算アプリです。スマホのブラウザで動き、ホーム画面に追加するとアプリのように使えます。インストール・会員登録・サーバーは不要で、データは端末の中だけに保存します。

事務所でまとめて片づける **パソコン版**（`pc/`、公開後は `https://…/keihi/pc/`）もあります → [パソコン版](#パソコン版)

## いちばん楽な使い方

1. レシートをもらったら **「撮る」** → 金額・日付・お店・勘定科目・登録番号（インボイス）・税率ごとの額が自動で入る
2. 黄色の欄（読み取りに自信がない所）だけ確かめて **「保存」**（続けて撮るなら「保存して次へ」）
3. 月末は **「精算」→「精算書 PDF を作る」→「送る」**（LINE・メールなど）。提出したら「精算済みにする」

たまったレシートは「写真から」でまとめて選べます。読み取りが終わると「確認待ち」に並ぶので **「まとめて確定」** の 1 回で終わります。

## できること

| 機能 | 内容 |
|---|---|
| 撮るだけ入力 | 金額（合計・お預り−お釣りで確かめ）、日付（西暦・令和・2 桁年・月日だけ）、支払先（主な店名は辞書で正しい名前に）、勘定科目、登録番号（T+13 桁・検査用数字で読みまちがいを確認・国税庁サイトへのリンク）、10%/8% 対象額、支払方法 |
| 自動切り抜き | 机などの背景が写っていたら、レシートの紙の部分だけを切り抜いて保存（読み取りもきれいになる） |
| 覚える | 自分で直した科目は支払先ごとに覚えて次から自動で選ぶ。登録番号と支払先の組み合わせも覚える。支払先を手で入れたときも科目を自動で選ぶ |
| 交通費 | 電車・バス（区間・往復・片道運賃）、自家用車（km × 単価、往復） |
| よく使う | 毎日の通勤・駐車場などを登録すると、ホームのボタン 1 回で今日の分が入る |
| 現場・案件 | 経費ごとに現場名を付けられる（前回の現場が最初から入っている）。精算書に現場別の集計 |
| 注意 | 同じ日・同じ金額の経費があると知らせる（二重登録防止）。1 人あたりの飲食額（1 万円以下の目安） |
| 精算書 PDF | A4。申請者・承認欄・立替合計・仮払金・差引支給額、明細、勘定科目別・現場別の集計、**領収書の台紙**（1 ページに 6 枚） |
| 会社払い | 会社カード・請求書払いは精算額に含めず、記録と領収書の保管用として載せる |
| CSV | Excel で開ける（BOM 付き）。一覧の絞り込み結果も書き出せる |
| 一覧・検索 | 月ごと・全期間、支払先・内容・現場・金額で検索、状態（未精算・精算済み・確認待ち）で絞り込み |
| 精算の履歴 | 作った精算書の作り直し、「未精算に戻す」 |
| バックアップ | 画像も含めて 1 つのファイルに保存・復元（API キーは含めない） |
| パソコン | 画像のドラッグ＆ドロップ・貼り付け（Ctrl+V）でも取り込める |
| Android | 写真アプリなどの「共有」から直接送れる（ホーム画面に追加したとき） |
| オフライン | 電波がなくても記録・精算書の作成ができる |

## パソコン版

`pc/index.html`（公開後は `https://…/keihi/pc/`）を Chrome か Edge で開きます。アドレスバーの［インストール］でアプリとして使え、エクスプローラーや Finder で画像・PDF を右クリック →「このアプリで開く」でも取り込めます。横幅 900px 以上で使えます。

### 画面

| 画面 | 内容 |
|---|---|
| ホーム | 今月の経費・未精算の立替・確認待ち・今年の合計、月ごとの経費（直近 12 か月）、勘定科目別・現場別の内訳（クリックで一覧に絞り込み）、最近の動き、よく使う |
| 確認待ち | 左に読み取った経費の一覧、中央に領収書（ホイールで拡大・ドラッグで移動・ダブルクリックで全体・右に回して読み直す）、右に入力欄。**Ctrl+Enter で確定して次へ**。そろったものは「まとめて確定」 |
| 経費一覧 | 月・年・期間で切り替え、状態・科目・現場・支払方法で絞り込み、検索、列の並べ替え。行をクリックすると右に詳細が開き、Alt+↑↓ で前後へ。チェック（Shift で範囲）して **科目・現場・支払方法をまとめて変更**（元に戻せる）、確定、精算書に、CSV、削除 |
| 精算書 | 左で期間・仮払金・申請者を決めると、右に A4 の仕上がりがそのまま出る。**PDF を保存・印刷（Ctrl+P）・CSV・会計ソフト用の仕訳 CSV**、精算済みにする、これまでの精算（PDF の作り直し・未精算に戻す） |
| 帳簿 | 売上・収入（売掛金の「入金を記録」つき）、振替伝票（よくある振替をボタンで）、仕訳帳（経費・売上・振替・精算から自動で作った仕訳）、帳簿の設定（個人事業主 / 法人・決算月・期首残高・支払方法ごとの科目） |
| 決算書 | **ボタンひとつで損益計算書・貸借対照表（PDF・月別推移つき）**。今期・前期・期間指定、貸借一致のチェック、マイナス残高などの注意、試算表・仕訳帳の CSV |
| よく使う | 登録した経費を「今日の分を追加」「日付を選んで」でワンクリック入力 |
| 設定 | 申請者、読み取り方（端末内 / AI）、入力の初期値、勘定科目、スマホのデータの取り込み・バックアップ、キーボード操作の一覧、表示の明るさ（自動・明るい・暗い） |

### 取り込み方

- 画面のどこにでも **ドラッグ＆ドロップ**（画像・PDF・スマホ版のバックアップ）
- ［取り込む］ボタン（Ctrl+O）、フォルダごと（Ctrl+Shift+O）、**貼り付け**（Ctrl+V。スクリーンショットなど）
- **電子の領収書（PDF）**: 文字のある PDF は文字をそのまま読むので正確（Amazon・モノタロウなどの領収書）。元の PDF も保存し、詳細からいつでも開けます

### キーボード

| キー | 操作 |
|---|---|
| Ctrl+K | 検索・操作（経費を支払先・金額で探す、画面の移動、取り込み など） |
| 1〜8 | ホーム / 確認待ち / 経費一覧 / 精算書 / 帳簿 / 決算書 / よく使う / 設定 |
| N | 手で入力 |
| ↑ ↓ ・ Enter ・ Space | 一覧の行を移動・詳細を開く・選ぶ |
| Ctrl+A ・ Delete ・ / | すべて選ぶ・選んだ経費を削除・検索 |
| Ctrl+Enter | 保存（確認待ちでは確定して次へ） |
| Alt+↑ ↓ | 前 / 次の経費 |
| Esc | 閉じる・選択をやめる |
| ? | キーボード操作の一覧 |

### 損益計算書・貸借対照表（決算書）

［決算書］の「損益計算書・貸借対照表を作る」を押すと、A4 の PDF（損益計算書・貸借対照表・月別推移の 3 ページ）ができます。検索・操作（Ctrl+K）から「損益計算書・貸借対照表を作る」でも、その場で PDF になります。

はじめに 1 回だけ、［帳簿 → 帳簿の設定］で次を入れます。

1. **帳簿の形**: 個人事業主（青色申告決算書の形: 売上・経費・所得、元入金・事業主貸・事業主借）か、法人（売上総利益・営業利益・経常利益、資本金・繰越利益剰余金）
2. **決算月**と**期首残高**（帳簿を始める日の現金・預金・売掛金・未払金・借入金など。分からない科目は 0 のままでよい）。次の期からは記録から自動で繰り越します
3. **支払方法ごとの科目**: 個人のお金で払った経費は、個人事業主なら「事業主借」、法人なら立て替えた人への「未払金」（初期値）

あとは記録するだけです。

| 記録 | 自動で作る仕訳 |
|---|---|
| 経費（確定したもの） | 借方 勘定科目 ／ 貸方 支払方法ごとの科目（事業主借・未払金・現金など） |
| 売上・収入 | 借方 入金先（売掛金・普通預金・現金）／ 貸方 売上高・雑収入・受取利息 |
| 売掛金の「入金を記録」 | 借方 普通預金（または現金）／ 貸方 売掛金 |
| 精算済み（法人のみ） | 借方 未払金 ／ 貸方 普通預金（仮払金があれば相殺） |
| 振替伝票 | 入れたとおり（借入・返済・生活費の引き出し・カードの引き落とし・減価償却など） |

- 期首の元入金（法人は繰越利益剰余金）は「期首の資産 − 期首の負債（− 資本金）」で決まるので、貸借は必ず一致します。一致しないときや、現金・預金・仮払金がマイナスになったときは、画面の「チェック」に理由と直し方が出ます。
- 確認待ちの経費は入りません（件数を知らせます）。
- 税込経理です。減価償却・棚卸・法人税等・青色申告特別控除は自動では計算しません（必要なら振替伝票で入れてください）。申告の前には、税理士や会計ソフトで確かめてください。

### スマホとパソコンで使う

データはサーバーに送らないので、ファイルで受け渡します。

1. スマホ版の［設定 → パソコンへ送る］で、LINE・メール・Google ドライブなどにバックアップのファイルを送る
2. パソコン版の画面にそのファイルをドラッグする（または［設定 → スマホのデータを取り込む］）
3. 新しい経費だけが加わり、同じ経費は新しく直した方が残ります。いまある経費は消えません

同じパソコンのブラウザでスマホ版（`keihi/`）とパソコン版（`keihi/pc/`）を開いた場合は、同じデータを使います。

### 会計ソフト用の仕訳 CSV

借方＝経費の勘定科目、貸方＝未払金（設定で変更可）。10% と 8% の対象額が分かれている経費は 2 行に分け、税区分（課対仕入10% / 課対仕入8%(軽) / 対象外）・適格請求書の有無・登録番号・現場も入れます。取り込むときは、会計ソフトの「仕訳の取り込み」で列を合わせてください。

## 読み取り方は 2 つ

| | 端末内で読む（初期設定） | AI で読む |
|---|---|---|
| 料金 | 無料 | Anthropic の API 料金（1 枚あたり数円程度。Haiku なら 1 円未満） |
| 画像 | 外に送らない | Claude（Anthropic）に送る |
| 精度 | 印字のレシートなら実用的。しわ・手書き・暗い写真は苦手 | 手書き・しわ・斜めでも強い。内容（品目）も短くまとめる |
| 準備 | はじめての読み取りだけ、読み取り用データ（約 6MB）をダウンロード | 設定で API キーを入れる（console.anthropic.com で作れます） |

- AI で読むときは、標準で **Claude Opus 5.5** を使います（設定で Sonnet 5.5・Haiku 5.5 に変更可）。読み取りの指示は軽め（effort: low）で、結果は決まった形（JSON スキーマ）で受け取ります。Opus・Sonnet では、安全上の理由で読み取りを断られたときにサーバー側で別のモデルが続ける設定（`fallbacks: "default"`）を付けています。
- AI に接続できない・キーがまちがっている・断られたときは、自動で端末内の読み取りに切り替えます。
- API キーはこの端末の中（ブラウザの保存領域）にだけ保存し、Anthropic 以外には送りません。共用の端末では使わないでください。

## 公開のしかた

このリポジトリを GitHub Pages で公開していれば、`https://…/keihi/` を開くだけで使えます（[現場CAD の公開方法](../README.md#使い方公開方法)と同じ手順）。スマホで開いて、共有メニューから **ホーム画面に追加** してください。

パソコンで試すだけなら、リポジトリのフォルダで `python3 -m http.server` を実行し、`http://localhost:8000/keihi/` を開きます。

## 注意

- 読み取り結果は必ず確かめてください（特に黄色の欄）。
- データはこの端末のブラウザの中にあります。ブラウザのデータを消す・機種変更するときは、先に **設定 → バックアップを保存** をしてください。
- 紙の領収書の保管や電子帳簿保存法への対応は、会社の決まりと税理士の指示に従ってください。このアプリは日付・金額・取引先で検索できる形で画像を残しますが、電子帳簿保存法の要件（タイムスタンプ・事務処理規程など）をすべて満たすものではありません。
- 登録番号の確認は形式（検査用数字）のチェックです。登録されている事業者かどうかは、リンク先の国税庁の公表サイトで確かめてください。

## ファイル構成

```
index.html             画面
app.css                見た目（明るい / 暗い表示）
js/app.js              スマホ版の画面と操作（ホーム・一覧・精算・設定・編集）
js/store.js            経費のデータ・学習・読み取りの順番待ち・精算の記録・バックアップと取り込み（スマホ版・パソコン版で共通）
js/pdfin.js            電子の領収書（PDF）の文字の読み取りと画像化（pdf.js）
js/books.js            帳簿: 勘定科目、仕訳の自動作成、期首残高からの繰越、損益計算書・貸借対照表・月別推移・試算表（端末に依存しない）
js/parse.js            レシートの文字から日付・金額・支払先・登録番号などを読む（端末に依存しない）
js/crop.js             写真からレシートの紙の範囲を見つける（端末に依存しない）
js/ocr.js              画像の準備、端末内 OCR（Tesseract.js）、Claude での読み取り
js/report.js           精算書・領収書台紙の作成、PDF・CSV の書き出し
js/db.js               端末内の保存（IndexedDB）
vendor/anthropic-sdk.mjs  Anthropic 公式 SDK（@anthropic-ai/sdk 1.10.0 をブラウザ用に 1 ファイルにまとめたもの。Apache-2.0、同梱分のライセンスは anthropic-sdk.LICENSE.txt）
pc/index.html          パソコン版の画面
pc/pc.js               パソコン版の画面と操作（ホーム・確認待ち・一覧・精算書・よく使う・設定・検索パレット・キーボード）
pc/editor.js           経費の詳細（右のパネル・確認画面）と領収書の画像ビューア
pc/charts.js           ホームのグラフ
pc/ui.js               アイコン・トースト・ダイアログ・メニュー
pc/pc.css              パソコン版の見た目（明るい / 暗い表示）
sw.js                  オフライン対応・Android の共有の受け取り（スマホ版・パソコン版の両方）
test/                  読み取り・切り抜き・帳簿のテスト（node --test test/*.test.mjs）
```

端末内 OCR の部品（tesseract.js 7.0.0・日本語データ）と PDF の読み取り（pdf.js 6.4.299）は jsDelivr から読み込み、一度使うと端末に保存されてオフラインでも動きます。

`vendor/anthropic-sdk.mjs` を作り直すとき:

```sh
npm install @anthropic-ai/sdk esbuild
printf 'export { default } from "@anthropic-ai/sdk";\nexport * from "@anthropic-ai/sdk";\n' > entry.mjs
npx esbuild entry.mjs --bundle --format=esm --platform=browser --minify --legal-comments=eof --outfile=vendor/anthropic-sdk.mjs
```
