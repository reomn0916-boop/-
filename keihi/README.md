# ラク経費

**レシートを撮るだけ**の経費精算アプリです。スマホのブラウザで動き、ホーム画面に追加するとアプリのように使えます。インストール・会員登録・サーバーは不要で、データは端末の中だけに保存します。

事務所でまとめて片づける **パソコン版**（`pc/`、公開後は `https://…/keihi/pc/`）もあります → [パソコン版](#パソコン版)

## いちばん楽な使い方

1. レシートをもらったら **「撮る」** → 金額・日付・お店・勘定科目・登録番号（インボイス）・税率ごとの額が自動で入る
2. 黄色の欄（読み取りに自信がない所）だけ確かめて **「保存」**（続けて撮るなら「保存して次へ」）
3. 月末は **「精算」→「精算書 PDF を作る」→「送る」**（LINE・メールなど）。提出したら「精算済みにする」

たまったレシートは「写真から」でまとめて選べます。読み取りが終わると「確認待ち」に並ぶので **「まとめて確定」** の 1 回で終わります。

| バックアップ | 画像も含めて 1 つのファイルに保存・復元（API キーは含めない） |

| Android | 写真アプリなどの「共有」から直接送れる（ホーム画面に追加したとき） |
| オフライン | 電波がなくても記録・精算書の作成ができる |
| 経理（パソコン版） | 損益計算書・貸借対照表、請求書（インボイス）と入金の消し込み、銀行・カード明細の取り込み、毎月の自動登録、文章で仕訳、固定資産と減価償却、消費税の計算、家事按分、青色申告決算書の内訳、弥生・マネーフォワード形式（freee は弥生形式で取り込み）、現場別の損益と実行予算、外注費の源泉徴収と支払調書、車両ごとの燃費、予算と通知、承認、同期フォルダ（自動バックアップ）、電子帳簿保存法の変更履歴、年次まとめ |

### 取り込み方

- 画面のどこにでも **ドラッグ＆ドロップ**（画像・PDF・**メール（.eml）**・**銀行・カードの明細（.csv）**・スマホ版のバックアップ・承認の提出 / 結果ファイル）
- **メールの領収書**: メールソフトからメールを .eml で保存してドラッグすると、添付の PDF・画像を取り込みます。添付がないメール（本文が領収書）は本文を読み取ります
- ［取り込む］ボタン（Ctrl+O）、フォルダごと（Ctrl+Shift+O）、**貼り付け**（Ctrl+V。スクリーンショットなど）
- **電子の領収書（PDF）**: 文字のある PDF は文字をそのまま読むので正確（Amazon・モノタロウなどの領収書）。元の PDF も保存し、詳細からいつでも開けます

### 損益計算書・貸借対照表（決算書）

［決算書］の「損益計算書・貸借対照表を作る」を押すと、A4 の PDF（損益計算書・貸借対照表・月別推移。課税事業者は消費税、個人事業主は決算書の内訳のページも）ができます。検索・操作（Ctrl+K）から「損益計算書・貸借対照表を作る」でも、その場で PDF になります。

はじめに 1 回だけ、［帳簿 → 帳簿の設定］で次を入れます。

1. **帳簿の形**: 個人事業主（青色申告決算書の形: 売上・経費・所得、元入金・事業主貸・事業主借）か、法人（売上総利益・営業利益・経常利益、資本金・繰越利益剰余金）
2. **決算月**と**期首残高**（帳簿を始める日の現金・預金・売掛金・未払金・借入金など。分からない科目は 0 のままでよい）。次の期からは記録から自動で繰り越します
3. **支払方法ごとの科目**: 個人のお金で払った経費は、個人事業主なら「事業主借」、法人なら立て替えた人への「未払金」（初期値）

あとは記録するだけです。

| 記録 | 自動で作る仕訳 |
|---|---|
| 経費（確定したもの） | 借方 勘定科目 ／ 貸方 支払方法ごとの科目（事業主借・未払金・現金など） |
| 売上・収入 | 借方 入金先（売掛金・普通預金・現金）／ 貸方 売上高・雑収入・受取利息 |
| 売掛金の「入金を記録」 | 借方 普通預金（または現金）／ 貸方 売掛金 |
| 精算済み（法人のみ） | 借方 未払金 ／ 貸方 普通預金（仮払金があれば相殺） |
| 振替伝票 | 入れたとおり（借入・返済・生活費の引き出し・カードの引き落とし など） |
| 請求書 | 売上と同じ（借方 売掛金 ／ 貸方 売上高）。10% と 8% を分けて消費税を計算 |
| 明細の取り込み | 口座: 経費は「科目 ／ 普通預金」、入金は「普通預金 ／ 売上高」か、同じ金額の請求があれば「普通預金 ／ 売掛金」で消し込み。カード: 「科目 ／ 未払金」。レシートで登録済みの出金・前に取り込んだ行は飛ばします |
| 外注費の支払い | 借方 外注費（総額）／ 貸方 普通預金（差引額）・預り金（源泉所得税） |
| 固定資産 | 買ったとき「資産 ／ 支払った科目」、期末ごとに「減価償却費 ／ 資産」（定額法・200%定率法・少額減価償却資産（1 年 300万円までをチェック）・一括償却資産。個人事業主は事業で使う割合を超える分を事業主貸に） |
| 家事按分（個人事業主） | 期末に「事業主貸 ／ 科目」で私用の割合を経費から外す |

- 期首の元入金（法人は繰越利益剰余金）は「期首の資産 − 期首の負債（− 資本金）」で決まるので、貸借は必ず一致します。一致しないときや、現金・預金・仮払金がマイナスになったときは、画面の「チェック」に理由と直し方が出ます。
- 確認待ちの経費は入りません（件数を知らせます）。
- 税込経理です。棚卸・法人税等・青色申告特別控除は自動では計算しません（必要なら振替伝票で入れてください）。申告の前には、税理士や会計ソフトで確かめてください。

### 消費税

［帳簿の設定 → 消費税］で「課税事業者」にすると、決算書の画面に納める消費税の見込みが出ます。一般課税・簡易課税（みなし仕入率を選ぶ）・2割特例（個人は 2026年分まで）・3割特例（個人の 2027年分から。令和8年度改正）を選べ、ほかの方法との差も出します。登録番号（インボイス）のない経費は、経過措置の割合（令和8年度改正後: 2026年9月30日まで 80%、2028年9月30日まで 70%、2030年9月30日まで 50%、2031年9月30日まで 30%）だけを控除します。電車・バス・車の距離精算は登録番号がなくても控除できる扱いです。家事按分した分と、固定資産の私用分は控除しません。

### 承認（ファイルで提出・承認）

1. 申請する人: ［精算書］で精算済みにしたあと、これまでの精算の ✈（承認に出す）か［承認 → 承認に出す］で提出ファイル（領収書の画像つき）を作り、メールやチャットで送る
2. 承認する人: 届いたファイルを画面にドラッグ → 領収書を見て、経費ごとのコメントを書いて「承認する」か「差し戻す」→ 結果ファイルを返す
3. 申請する人: 結果ファイルをドラッグ → 精算に結果が付き、コメントは経費の詳細に出ます（差し戻しなら「未精算に戻す」で直して出し直す）

### Google ドライブで同期（スマホ・パソコン）

［設定］で［Google ドライブにつなぐ］を押すと、マイドライブの `ラク経費` フォルダにデータと領収書の画像を自動で保存し、**スマホとパソコンのデータが自動でそろいます**（変更から 20 秒後・10 分ごと・アプリに戻ったとき）。サーバーはいりません。同期は **1 人 1 アカウント**（自分のスマホとパソコンをそろえる用）です。社員みんなで同じアカウントを使うと経費と名前が混ざるので、会社への提出は「提出ファイル」で総務に送ります（下の「総務」）。つながりは 1 時間で切れるので、「つなぎ直す」が出たら押してください。最初に 1 回だけ Google の OAuth クライアント ID を作ります（[docs/google-drive.md](docs/google-drive.md)）。

### 総務（全員の精算を集めて払う）

パソコン版の［承認・総務］に、総務向けの画面があります。

| タブ | できること |
|---|---|
| 受け取り箱 | 社員から届いた提出ファイルを**まとめてドラッグ**。社員別・月別・状態（未決・承認・差し戻し・支払済み）で一覧、**未提出の人**とお知らせ文、**会社のルールに合わない経費**と、**ほかの社員の提出にも同じ日・金額・支払先がある経費（二重申請の疑い）**の印、全員の経費の検索（電子帳簿保存法）、問題のないものをまとめて承認、全員分の明細 CSV |
| 振込 | 振込元（委託者コード・会社の口座）を入れ、承認済み・未払いの精算を社員ごとにまとめて、**全銀協規定形式（総合振込）の振込データ**と振込一覧 CSV を作る。払ったら「支払済み」に |
| 社員と振込先 | 名簿（提出ファイルの名前・社員番号・振込先で自動で増える。総務が直した振込先は固定）、在籍・退職 |
| 会社のルール | 締切日・必須項目（目的・現場・画像・飲食の人数と相手）・飲食の 1 人あたり上限・科目ごとの上限・使える科目を決め、**配るファイル**を作る。社員が取り込むと入力の画面と提出のときに知らせる |
| 自分の精算 | 自分の精算を総務に提出する・結果を見る |

社員はスマホの［精算］→［精算書 PDF を作る］→［精算済みにして総務に提出］で、明細・領収書の画像・振込先の入った提出ファイルを送ります。名前・所属・社員番号・振込先は端末ごとの情報で、同期で上書きされません。

全銀形式の振込データ（1 行 120 桁・半角カナ・Shift_JIS）は、銀行によって細かい条件が違うことがあるので、はじめは少額で取り込めるか確かめてください。

**総務の合言葉**: ［承認・総務］の総務向けタブは、合言葉（6 文字以上）を入れたときだけ開きます（15 分さわらないと閉じる）。社員の振込先・会社の振込元は合言葉から作った鍵（PBKDF2 25 万回 → AES-GCM）で暗号化して保存し、バックアップ・同期のファイルにもふつうの形では入れません。受け取り箱の提出は口座の下 4 けただけ残します。承認・振込データ・振込先の変更などは操作の記録に残ります。ブラウザだけの仕組みなので、開発者ツールでの書き換えまでは防げません（完全に分けるにはサーバー版）。

### 帳簿の締め

［帳簿 → 帳簿の設定］で月末を選んで締めると、その日までの仕訳を固定して保存します。締めた期間の決算書は、あとで経費や設定を変えても変わりません。締めた期間の経費・売上・振替は数字に関係する欄を直す・消す・その日付で新しく入れることができず、銀行明細の取り込みでも飛ばします。戻すときは理由を入れ、記録に残ります。締めはバックアップ・同期に入ります。

### 同期フォルダ（自動バックアップ・ほかのパソコンと同期）

経費・帳簿・精算（承認の結果も）・設定（固定資産・予算・期首残高など）・よく使う・毎月の自動登録・変更の履歴を同期します。消した記録も、ほかのパソコンで消えます（消した印を 400 日残します）。同じ記録を両方で直したときは、あとで直した方が残ります。毎月の自動登録は、2 台で動いても同じ月が 2 件になりません。

［設定 → 同期・自動バックアップ］で Google ドライブ・OneDrive・Dropbox などのフォルダを選ぶと、変更から 20 秒後と 10 分ごとにそのフォルダへ保存し、7 日分の控えも残します。別のパソコンで同じフォルダを選ぶと、お互いの変更を取り込み合います（Chrome・Edge。ブラウザを開き直したときは許可をもう一度押します。API キーは保存しません）。

### 電子帳簿保存法

確定した経費・帳簿の記録を直したり消したりすると、いつ・何を・どう変えたかを自動で記録します（経費の詳細の「変更の履歴」、［設定 → 変更の履歴を見る］、CSV）。経費一覧は日付・金額の範囲・取引先で検索できます。［事務処理規程のひな形］で、訂正削除の防止に関する事務処理規程の下書きを保存できます。

### スマホとパソコンで使う

データはサーバーに送らないので、ファイルで受け渡します。

1. スマホ版の［設定 → パソコンへ送る］で、LINE・メール・Google ドライブなどにバックアップのファイルを送る
2. パソコン版の画面にそのファイルをドラッグする（または［設定 → スマホのデータを取り込む］）
3. 新しい経費だけが加わり、同じ経費は新しく直した方が残ります。いまある経費は消えません

同じパソコンのブラウザでスマホ版（`keihi/`）とパソコン版（`keihi/pc/`）を開いた場合は、同じデータを使います。

### 会計ソフト用の仕訳 CSV

［決算書 → CSV］から、期間のすべての仕訳を書き出せます（Shift_JIS）。

| ソフト | 形式 | 取り込み方 |
|---|---|---|
| 弥生会計・やよいの青色申告 | 弥生インポート形式（25 列）。税区分は税込経理の記述（例: 課対仕入込10%適格、課対仕入込10%区分70%、課税売上込軽減8%）。減価償却・家事按分は「本決」 | ［ファイル → インポート］ |
| マネーフォワード クラウド会計・確定申告 | 仕訳帳のサンプルフォーマット（A〜AA 列）。税区分（課税仕入 10% など）とインボイス（適格・70％控除など）。10% と 8% の行は同じ取引No（複合仕訳） | ［会計帳簿 → 仕訳帳 → インポート → 仕訳帳］ |
| freee 会計 | 弥生インポート形式 | ［取引 → 振替伝票 → インポート → 弥生会計仕訳インポート］ |

列と税区分は各社の公式の説明（弥生「仕訳データの項目と記述形式」「課税方式別税区分・税計算区分一覧」、マネーフォワード「「仕訳帳」をインポートする」）に合わせています。freee の説明ページはこの環境から読めなかったため、freee では弥生形式の取り込み機能を使います。勘定科目の名前が会計ソフト側と違うときは、取り込み画面で対応づけを聞かれます。下は［精算書］［経費一覧］の経費だけの仕訳 CSV です。

借方＝経費の勘定科目、貸方＝未払金（設定で変更可）。10% と 8% の対象額が分かれている経費は 2 行に分け、税区分（課対仕入10% / 課対仕入8%(軽) / 対象外）・適格請求書の有無・登録番号・現場も入れます。取り込むときは、会計ソフトの「仕訳の取り込み」で列を合わせてください。

## 読み取り方は 2 つ

| | 端末内で読む（初期設定） | AI で読む |
|---|---|---|
| 料金 | 無料 | Anthropic の API 料金（1 枚あたり数円程度。Haiku なら 1 円未満） |
| 画像 | 外に送らない | Claude（Anthropic）に送る |
| 精度 | 印字のレシートなら実用的。しわ・手書き・暗い写真は苦手 | 手書き・しわ・斜めでも強い。内容（品目）も短くまとめる |
| 準備 | はじめての読み取りだけ、読み取り用データ（約 6MB）をダウンロード | 設定で API キーを入れる（console.anthropic.com で作れます） |

- AI で読むときは、標準で **Claude Opus 5.5** を使います（設定で Sonnet 5.5・Haiku 5.5 に変更可）。読み取りの指示は軽め（effort: low）で、結果は決まった形（JSON スキーマ）で受け取ります。Opus・Sonnet では、安全上の理由で読み取りを断られたときにサーバー側で別のモデルが続ける設定（`fallbacks: "default"`）を付けています。
- AI に接続できない・キーがまちがっている・断られたときは、自動で端末内の読み取りに切り替えます。
- API キーはこの端末の中（ブラウザの保存領域）にだけ保存し、Anthropic 以外には送りません。共用の端末では使わないでください。

## 公開のしかた

このリポジトリを GitHub Pages で公開していれば、`https://…/keihi/` を開くだけで使えます（[現場CAD の公開方法](../README.md#使い方公開方法)と同じ手順）。スマホで開いて、共有メニューから **ホーム画面に追加** してください。

パソコンで試すだけなら、リポジトリのフォルダで `python3 -m http.server` を実行し、`http://localhost:8000/keihi/` を開きます。

## 注意

- 読み取り結果は必ず確かめてください（特に黄色の欄）。
- データはこの端末のブラウザの中にあります。ブラウザのデータを消す・機種変更するときは、先に **設定 → バックアップを保存** をしてください。
- 紙の領収書の保管や電子帳簿保存法への対応は、会社の決まりと税理士の指示に従ってください。このアプリは日付・金額・取引先で検索できる形で画像を残しますが、電子帳簿保存法の要件（タイムスタンプ・事務処理規程など）をすべて満たすものではありません。
- 登録番号の確認は形式（検査用数字）のチェックです。登録されている事業者かどうかは、リンク先の国税庁の公表サイトで確かめてください。

`vendor/anthropic-sdk.mjs` を作り直すとき:

```sh
npm install @anthropic-ai/sdk esbuild
printf 'export { default } from "@anthropic-ai/sdk";\nexport * from "@anthropic-ai/sdk";\n' > entry.mjs
npx esbuild entry.mjs --bundle --format=esm --platform=browser --minify --legal-comments=eof --outfile=vendor/anthropic-sdk.mjs
```
