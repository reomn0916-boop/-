# 案件ボード

チームで案件と作業を共有して管理する Web アプリです。スマホと PC のブラウザで使えます。

- 公開ページ: https://claude.ai/artifact/G2xFQttNwaQrHGNYbptNTd
- ソース: `app/index.html`

## できること

- **今日（ホーム）**: 開くと最初に出る画面です。次のものを1画面にまとめます。押すとそれぞれの画面へ移ります。
  - 今朝の報告
  - 今日・明日が期限のもの
  - 自分の担当カード
  - 自部署宛ての依頼（編集者は承認待ちも）
  - 今日の手配
  - 材料の知らせ
  - 未確認の伝票
- **現場（現場モード）**: スマホ向けの大きいボタンの画面です。
  - 「写真で記録」: カメラで撮ってひとこと添えると、選んだ現場のカードに記録されます。
  - 「レシートを撮る」: 撮るだけで経費に登録されます。AIが読める表示では読み取り、読めない表示では写真だけを登録します。確認は経理がまとめて行います。
  - 「今日の手配と予定」: 今日の手配と、工期中の現場を表示します。
- **依頼の定型文**: 依頼フォームで「出来高報告 → 請求のお願い」「発注の判断」「工程の遅れ」「資金繰りの警告」など10種類から選ぶと、差出・宛先・金額関係の印・本文の下書きが入ります。
- **カードの進み具合**: ボードのカードに、予算の消化率・未発注の材料数・未完了の依頼数・今日の手配人数を小さく表示します。
- **カンバンボード**: 未着手 → 進行中 → 確認待ち → 完了 の4列で管理します。カードはドラッグで移動できます。スマホでは長押ししてからドラッグします。
- **カレンダー**: 工期（開始日〜期限）を月表示で確認できます。日付をタップすると、その日の予定が一覧で出ます。
- **記録**: カードごとにメモと写真を時系列で残せます。写真は自動で縮小してから保存します。
- **絞り込み**: 案件名、自分の担当、キーワードで絞り込めます。
- 期限が近いカードは橙、期限を過ぎたカードは赤で表示します。
- **原価（予算と実績）**: カード詳細に「予算」を入れると、経費の実績と比べた消化率・残り・超過を表示します。予算を超えたカードには「予算超過」が付きます。
- **材料（拾い出し・発注管理）**: 工事ごとに、材料・規格・設計数量・ロス率・単価・使用予定日・仕入先・発注状況・納品予定日・図面番号を1行ずつ管理します。
  - 必要数量と金額は自動で計算します。
  - 次の場合に知らせを出します：要発注（使用日まで7日以内）、納品遅れ、納品が使用日に間に合わない、要判断（金額が基準以上）、要確認。
  - 「経営に判断を依頼」「経理に支払予定を連絡」で、部署間連絡に依頼を作ります。
  - 「📷 数量表・図面から拾い出す」で、写真からAIが行を起こします。起こした行には「要確認」が付きます。
  - CSV で書き出せます。
- **手配（職人・協力会社）**: 週ごとの表で、職人・協力会社をどの日にどの現場へ入れるかを割り当てます。
  - 案件別の人工を集計します。カードに「必要人工」を入れると、工期中の不足日が赤く出ます。
  - カレンダーで日付を選ぶと、その日の手配も表示します。
- **経費（レシート・伝票の集計）**: レシート・領収書・納品書・請求書の写真を選ぶと、AIが読み取って登録します。読み取る項目は、日付・取引先・品目・税込金額・消費税（10%/8%）・インボイス登録番号・勘定科目・支払方法です。複数枚まとめて選べます。
  - 読み取る前に案件を選んでおくと、その案件にひも付けて登録します。
  - 月ごとに、合計・消費税・未確認件数・インボイス番号なしの件数を表示します。勘定科目別と案件別の集計も出ます。
  - 一覧で注意を促す印を付けます：未確認、インボイス番号なし、重複の可能性（同じ日付・金額・取引先）、読み取りが不確か。
  - 「CSVを書き出す」で、その月の明細を Excel で開ける CSV にします。税理士への提出や会計ソフトへの取り込みに使えます。
  - 案件カードの詳細に「この案件の経費」（合計と科目別）を表示します。
- **立替精算**: 経費タブで、未精算の立替を人ごとに合計します。編集者が「精算済みにする」を押します。
- **写真帳・工事カルテ**（カード詳細）:
  - 記録の写真を、A4 で印刷できる工事写真帳（HTML）に書き出します。
  - 予算・経費・材料・人工・記録から、AIが工事カルテ（Markdown）を作ります。カルテはカードに保存され、コピーして Obsidian に貼れます。雛形は「AIの指示文」で編集できます。
- **資料（仕分け）**: 選んだ資料をAIが「有用・不要・要確認」と入れる先に分けます。社長が「確定」を押します。削除はしません。
- **連絡（部署間連絡）**: 「部署間連絡ボード」を取り込んだ画面です。経理・経営・施工管理の間の依頼を、宛先ごとのタブで見られます。依頼を出す、回答する、完了にする、までここで行います。
  - 金額・契約・支払に関わる依頼は、オーナー（編集者）が「承認して完了」を押すまで「確認待ち」に留まります。
  - 完了した依頼は「過去ログ」に移ります。
  - 依頼は案件カードにひも付けられます。カードの詳細から「この案件で他部署に依頼」を押してください。
  - 画面右の「部署別の共有情報」は、各部署が自分の欄を上書きして使います。
  - 「自分の部署」を選ぶと、自部署宛ての未完了件数が「連絡」タブのバッジに出ます。編集者のバッジには承認待ちの件数も入ります。
- **AI（元の各部署プロジェクトと監査役の置き換え）**
  - 「AIで振り分け」: 未振り分けの依頼について、内容から宛先の部署を決めます。
  - 「AIで回答案」: 宛先部署の指示文と共有情報をもとに回答の下書きを作ります。人が確認してから保存します。
  - 「監査役チェック」: 回答を点検します。
    - 合格して重要（要承認）なら承認待ちへ、軽微なら完了にします。
    - 不合格のときは所見と修正案を出します。3回続けて不合格なら「要確認」として承認待ちの先頭に置きます。
  - 指示文は画面右の「AIの指示文」で編集できます（オーナー・編集者のみ）。重要の金額基準（初期値50万円）もここで変えられます。
  - AI は押した人の Claude 利用枠で動きます。

## チームでの使い方

ページの共有メニューからメンバーを招待してください。
カードの追加・編集や写真の投稿をするには「Contributor」以上の権限が必要です。

## 毎朝の自動整理（スケジュール実行）

「部署間連絡 朝の整理」として、毎日 2:50（日本時間）に実行します。
アプリの共有データを直接読み書きし、次の作業を行います。

- 未振り分けの依頼を振り分ける
- 回答済みの依頼を監査役の基準で点検する
- 期限切れの依頼を一覧にする
- 今日・明日が期限の依頼・カード、使用日が3日以内で未発注の材料、今日・明日の手配を報告する
- 経費の未確認・インボイス番号なし・未精算の立替、材料の要発注・納品遅れ・経営の判断待ち、予算超過の案件を報告する（読むだけで、変更はしない）

金額・契約・支払に関わる依頼は自動で完了にしません。
結果は「連絡」タブ上部の「今朝の報告」に保存されます。過去14日分を日付で切り替えて見られます。完了時にはスマホへも通知が届きます。
