導入する人・管理する人向け

現場CAD 導入手順

アプリを公開して、スマホとパソコンに入れ、使える状態か確かめるまでの手順です。上から順に進めてください。全部で 30 分ほどです。

  1. 公開するGitHub で一度だけ。管理する人が行う
  2. スマホに入れる現場で使う人が、それぞれのスマホで
  3. パソコンに入れる事務所のパソコンで
  4. 動くか確かめる練習データで一通り試す

準備するもの

GitHub のアカウント
アプリの置き場所として使います（管理する人だけ）。アプリのファイルが入ったリポジトリが必要です。
スマホ
iPhone（iOS 16.4 以降・Safari）または Android（Chrome）。GPS を使うなら位置情報が使えるもの。
パソコン
Windows 10 / 11 に Google Chrome か Microsoft Edge。ほかのブラウザでも動きますが、上書き保存・連携フォルダ・アプリとしてのインストールは Chrome / Edge だけです。
あると便利
Google ドライブ（パソコン版）や OneDrive など、スマホとパソコンで共有できるクラウドの保存場所。LINE やメールでも代わりになります。
データの置き場所について図面や座標のデータは、使っているスマホ・パソコンの中だけに保存されます。インターネット上のサーバーには送りません。端末どうしは .gcad ファイルを送ってやりとりします。

段階 1アプリを公開する 管理する人

アプリはインターネットのページとして公開します。GPS（位置情報）は https のページでしか使えないため、GitHub Pages を使います。一度設定すれば、あとは何もしなくて構いません。

  1. GitHub でアプリのリポジトリを開き、上の Settings を押す。
  2. 左の一覧から Pages を選ぶ。
  3. 「Build and deployment」の Source を Deploy from a branch にする。
  4. Branch でアプリが入っているブランチ（今は claude/mobile-cad-app-kns1zg）を選び、フォルダは / (root) のまま Save。あとで main ブランチにまとめたら、ここを main に変えます。
  5. 1〜2 分待って画面を更新すると、上に「Your site is live at …」とアドレスが出ます。これがスマホ版のアドレスです。

アドレスは次の形です。このリポジトリなら、次のようになるはずです（表示されたものを正としてください）。

https://reomn0916-boop.github.io/-/

パソコン版のアドレスは、その最後に pc/ を付けたものです。

https://reomn0916-boop.github.io/-/pc/
公開範囲の注意 GitHub Pages のページは、アドレスを知っていれば誰でも開けます。開けるのはアプリの画面だけで、各自が入れた図面や座標は見えません。 無料のプランでは、公開（Public）のリポジトリしか Pages を使えません。リポジトリを非公開にしたい場合は、GitHub の有料プラン（Pro / Team など）が必要です。

アプリを新しくするとき

同じブランチに新しいファイルを入れると、1 分ほどで公開中のアプリも新しくなります。スマホ・パソコンでは、次にアプリを開いたときに新しい版が読み込まれます。古いままのときは、アプリを一度完全に閉じて開き直します。

段階 2スマホに入れる 現場で使う人

iPhone

  1. Safari でスマホ版のアドレスを開く。
  2. 下の 共有（四角から矢印が出たマーク）を押す。
  3. ホーム画面に追加 → 追加。ホーム画面に「現場CAD」のアイコンができます。
  4. 以後は必ずホーム画面のアイコンから開く。

Android

  1. Chrome でスマホ版のアドレスを開く。
  2. 右上の ⋮ → ホーム画面に追加（または「アプリをインストール」）。
  3. インストール を押す。アプリの一覧とホーム画面にアイコンができます。
  4. 以後はアイコンから開く。
iPhone はホーム画面のアイコンから使うiPhone では、Safari で開いたページと、ホーム画面のアイコンで開いたアプリは、別々にデータを持ちます。Safari で作った図面は、アイコンのアプリからは見えません。最初からアイコンのほうで使ってください。

はじめに一度だけ設定すること

  1. 位置情報を許可する: 下の GPS を押すと「位置情報の利用を許可しますか」と出るので 許可。 出ないとき（iPhone）: 設定 → プライバシーとセキュリティ → 位置情報サービス → Safari の Web サイト → 「使用中のみ」、「正確な位置情報」をオン。
    （Android）: Chrome の ⋮ → 設定 → サイトの設定 → 位置情報 で、このアドレスを許可。
  2. 座標系を決める: 上の帯の 系: 未設定 を押して、現場の平面直角座標系（例: 東京は第 9 系）を選ぶ。GPS を ON にすると自動で決まります。
  3. 表示の好みを決める: ☰ メニューの下の「設定」で、寸法の単位（m / mm）、点名の頭文字（例: P、K）、ダーク表示などを選ぶ。

段階 3パソコンに入れる 事務所

  1. Chrome か Edge でパソコン版のアドレス（最後が pc/）を開く。
  2. アドレス欄の右にある インストール のマーク（画面と下向き矢印）を押し、インストール。 マークがないとき: Chrome は ⋮ → キャスト、保存、共有 → ページをアプリとしてインストール。Edge は … → アプリ → このサイトをアプリとしてインストール。
  3. アプリが別の窓で開きます。スタートメニューやタスクバーから、ふつうのソフトと同じように開けます。

はじめに一度だけ設定すること

  1. 名前と座標系: ファイル タブ → 名前・座標系 で、座標系と点名の頭文字を決める。
  2. 縮尺・用紙・入力単位: リボンの下の帯で、よく使う縮尺（例 1:100）、用紙（例 A3 横）、入力単位（m / mm）、寸法の表示（mm / m）を選ぶ。次に開いたときも同じ設定になります。
  3. .gcad をダブルクリックで開けるようにする: インストールした後、エクスプローラーで .gcad ファイルをダブルクリックし、「このファイルを開く方法」で 現場CAD PC を選んで「常にこのアプリを使う」。 Chrome / Edge のアプリとしてインストールしたときだけ出ます。出ないときは、アプリの ファイル → 開く か、画面へのドラッグで開けます。
  4. 連携フォルダ（使う場合）: Google ドライブ（パソコン版）や OneDrive をパソコンに入れ、同期されるフォルダを作っておく。アプリの 現場連携 タブ → フォルダ設定 → フォルダを選ぶ で、そのフォルダを選び、「ファイルの編集を許可」で 許可。 アプリを開き直すと、また許可を聞かれることがあります。そのときも許可してください。
現場の人へアドレスを渡すパソコン版の 現場連携 タブ → スマホ版の開き方 で、スマホ版のアドレスと QR コードが出ます。スマホのカメラで読み取れば、すぐ開けます。

段階 4動くか確かめる

練習用のデータ（倉庫A）で、スマホとパソコンのやりとりまで一通り試します。全部にチェックが付けば導入完了です。

済確かめることうまくいった印
パソコン版のスタート画面で 練習用の図面を開く倉庫A の図面と K1〜K3 が出る
パソコン版の 図形編集 → 縮尺合わせ で寸法線「24,000」を選んで合わせる建物の長い辺が 24.000 m になる
Ctrl+P → PDF を保存図面枠と表題欄の付いた PDF が開ける
現場連携 → 現場へ送る → 保存して、LINE やメールでスマホへスマホに .gcad が届く
スマホ版の ☰ → パソコンから受け取る でそのファイルを選ぶ同じ図面がスマホに出る
外で GPS を押す左上に現在地の X・Y が出る（誤差は数 m）
スマホで建物の角に点を 1 つ置き、パソコンへ送る → パソコンで 現場データ取込「追加 1」と出て、パソコンの図面にその点が出る
スマホの SIMA で書き出す・送る → いつも使っている TS に取り込む点名が化けずに入る
パソコン版の ファイル → DXF で書き出し、いつも使っている CAD で開く画層・色・文字が読める

最後の 2 つ（TS と CAD）は機種やソフトによって違うので、使っているもので必ず一度試してください。うまくいかないときは、その機種名と症状を記録しておくと直しやすくなります。

データの保存とバックアップ

  • アプリは自動で保存しますが、保存先はその端末の中だけです。大事な図面は、ときどき .gcad で保存して、クラウドやパソコンに残してください（スマホ: ☰ → プロジェクトを保存、パソコン: Ctrl+S）。
  • スマホを買い替えるときは、古いスマホで .gcad を保存して新しいスマホで開きます。
  • ブラウザの「履歴とWebサイトデータを消去」などをすると、アプリの中のデータも消えます。消す前に .gcad で保存してください。

困ったとき

アドレスを開くと「404」になる

公開の設定から 1〜2 分たっていないか、Pages で選んだブランチが違います。Settings → Pages の表示を確かめてください。パソコン版はアドレスの最後に pc/ が必要です。

GPS が動かない・位置が出ない

アドレスが https で始まっているか、位置情報を許可したか（段階 2）を確かめてください。屋内やビルの谷間では出にくいので、空の見える場所で試します。

新しくしたはずなのに古い画面のまま

アプリを一度完全に閉じて（iPhone は下から上にスワイプして消す）、開き直してください。それでも古いときは、少し時間をおいてもう一度。

iPhone で、Safari で作った図面がアイコンのアプリにない

Safari とホーム画面のアプリは別々にデータを持ちます。Safari 側で ☰ → プロジェクトを保存（.gcad）して、アプリ側で開いてください。

スマホで送られてきた .gcad が選べない

iPhone は LINE やメールの添付を「ファイルに保存」してから、アプリの ☰ → パソコンから受け取る で「ファイル」の中から選びます。Android は「ダウンロード」フォルダに入っています。

パソコンでインストールのマークが出ない

Chrome か Edge で開いているか、アドレスの最後が pc/ になっているかを確かめてください。会社のパソコンで管理者が制限している場合は、インストールせずにブラウザのまま使えます（上書き保存は「名前を付けて保存」になります）。

連携フォルダで毎回「許可」を聞かれる

ブラウザの安全のための動きです。アプリを開き直したときに一度許可すれば、その間は聞かれません。
