# 現場CAD

スマホのブラウザで動く、現場向けの簡易 CAD です。図面の寸法・面積をその場で確認でき、GPS で現在地を **平面直角座標（X・Y）** に変換して記録できます。インストール不要で、ホーム画面に追加するとオフラインでも使えます。

## できること

| 機能 | 内容 |
|---|---|
| 作図 | 点・線（連続）・円。タップで配置し、端点・中点・線上・円周上に自動スナップ |
| 座標入力 | `X,Y`（絶対）／`@ΔX,ΔY`（相対）／`@距離<方向角`（極座標、角度は `45-30-15` のような度分秒も可） |
| 計測 | 距離（水平距離・方向角・ΔX/ΔY）、3点のなす角、面積（㎡・坪）・周長 |
| 情報表示 | 図形をタップで長さ・座標・緯度経度。端点や頂点をまとめて点として登録可能 |
| GPS | 現在地を平面直角座標（1〜19系）へ変換。10回平均で点を登録。選んだ点までの距離・方向を表示（杭探し用） |
| 読み込み | DXF（LINE / LWPOLYLINE / POLYLINE / POINT / CIRCLE / ARC / TEXT / MTEXT、Shift_JIS 対応）、SIMA、CSV |
| 書き出し | DXF（R12）、SIMA、CSV（Excel 用 BOM 付き）、プロジェクト JSON |
| 保存 | 端末内（localStorage）に自動保存。元に戻す対応 |

座標の向きは測量と同じく **X＝北、Y＝東**、方向角は北から時計回りです。DXF では DXF の X＝東、Y＝北として読み書きします。

## 使い方（公開方法）

GPS（位置情報）は **https** でしか使えないため、GitHub Pages などで公開して使います。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を「Deploy from a branch」、ブランチとフォルダ（`/ (root)`）を選んで保存
3. 表示された URL をスマホで開き、共有メニューから **ホーム画面に追加**

PC で試すだけなら、このフォルダで `python3 -m http.server` を実行して `http://localhost:8000` を開きます（localhost では GPS も動作します）。

## 精度について

- 座標変換は国土地理院の計算式（JGD2011 / GRS80）で、mm 以下の精度です。
- ただしスマホの GPS 自体の精度は数 m 程度です。境界や杭打ちなど精度が必要な作業は、測量機器で確認してください。
- 表示される距離は平面直角座標上の距離（縮尺係数を補正しない値）です。

## ファイル構成

```
index.html            画面
css/style.css         見た目
js/app.js             作図・スナップ・計測・GPS・UI
js/geo.js             緯度経度 ⇔ 平面直角座標の変換、角度の書式
js/io.js              DXF / SIMA / CSV の読み書き
sw.js                 オフライン用 Service Worker（更新時は VERSION を上げる）
manifest.webmanifest  ホーム画面追加用の設定
icons/                アイコン
```
