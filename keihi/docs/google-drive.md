# Google ドライブにつなぐ準備（現場CAD・ラク経費 共通）

サーバーなしで、スマホとパソコンのデータを Google ドライブで自動同期します。最初に 1 回だけ、Google Cloud で **OAuth クライアント ID** を作ります（無料・10〜15 分）。

## できること・決まりごと

- **ラク経費**: マイドライブ › `ラク経費` フォルダに、端末ごとのデータ・領収書の画像（1 枚ずつ）・14 日分の控えを保存します。スマホで撮ったレシートが、そのままパソコン版に出ます。
- **現場CAD**: マイドライブ › `現場CAD` フォルダに、プロジェクトごとの `.gcad` を保存します。スマホとパソコンで同じプロジェクトを開いていると、差分で取り込み合います（同じ図形は新しく直した方が残る）。
- 変更から少しあと・5〜10 分ごと・アプリに戻ったときに、自動で同期します。
- アプリが読み書きするのは、**このアプリが作ったファイルだけ**です（`drive.file` 権限）。ほかのファイルは見えません。
- **同期は 1 人 1 アカウントです。** 自分のスマホとパソコンを、自分の Google アカウントでつなぎます。社員みんなで同じアカウントを使うと、全員の経費と名前が混ざるので使わないでください。会社（総務）への提出は、アプリの「提出ファイル」で行います。使う人全員のアカウントを、手順 3 のテストユーザーに追加してください（100 人まで）。全員のデータを 1 か所で持ちたいときはサーバー版です（`server-plan.md`）。
- つながりは **1 時間で切れます**。切れると「つなぎ直す」が出るので、押してください（すぐ同期を再開します）。ブラウザに Google のログインが残っていれば、パスワードは要りません。

## 1. Google Cloud でプロジェクトを作る

1. パソコンで https://console.cloud.google.com/ を開き、Google アカウントでログインします。
2. 上の「プロジェクトを選択」→［新しいプロジェクト］。名前は `genbacad` などで作成します。

## 2. Google Drive API を有効にする

1. 左のメニュー［API とサービス］→［ライブラリ］。
2. 「Google Drive API」を検索して開き、［有効にする］。

## 3. 同意画面（アプリの名前）を作る

画面の名前は時期によって違います（［OAuth 同意画面］または［Google Auth Platform］）。

1. ［OAuth 同意画面］（または［Google Auth Platform］→［ブランディング］）を開きます。
2. アプリ名（例: 現場CAD・ラク経費）、サポートのメール（自分のアドレス）を入れます。
3. 対象（ユーザーの種類）は **外部**。
4. ［テストユーザー］（または［対象］→［テストユーザー］）に、**使う Google アカウント**を追加します。テストのままで、100 アカウントまで使えます。
5. スコープ（［データアクセス］）は、追加しなくても大丈夫です（アプリが `drive.file` だけを求めます）。

## 4. OAuth クライアント ID を作る

1. ［API とサービス］→［認証情報］（または［Google Auth Platform］→［クライアント］）→［認証情報を作成］→［OAuth クライアント ID］。
2. アプリケーションの種類: **ウェブ アプリケーション**。
3. **承認済みの JavaScript 生成元** に、公開している場所の「先頭部分」を入れます。
   - GitHub Pages なら: `https://（GitHub のユーザー名）.github.io`（後ろの `/リポジトリ名/` は付けない）
   - 自分のパソコンで試すなら: `http://localhost:8765` なども追加できます
4. 「承認済みのリダイレクト URI」は空のままで大丈夫です。
5. ［作成］→ 表示された **クライアント ID**（`…apps.googleusercontent.com`）をコピーします。クライアント シークレットは使いません。

## 5. アプリに入れる

どちらか 1 つ。

- **おすすめ**: リポジトリの `config.js` の `GOOGLE_CLIENT_ID = ''` の `''` の中に貼り付けて、コミット・公開します。全部の端末で入力が要らなくなります（クライアント ID は秘密の情報ではありません）。
- **すぐ試す**: 各アプリで［Google ドライブにつなぐ］を押すと ID を聞かれるので、貼り付けます（その端末だけに保存）。

## 6. つなぐ

| アプリ | 場所 |
|---|---|
| ラク経費（スマホ） | ［設定］→［Google ドライブにつなぐ］ |
| ラク経費（パソコン） | ［設定 → 同期・自動バックアップ］→［Google ドライブにつなぐ］ |
| 現場CAD（スマホ） | メニュー →［Google ドライブに保存・同期］／［Google ドライブから開く］ |
| 現場CAD（パソコン） | リボン［現場連携］→［ドライブと同期］／［ドライブから開く］ |

はじめてのときは Google の画面で「このアプリは Google で確認されていません」と出ることがあります（テスト中のため）。自分で作ったアプリなので［続行］で進めます。

## うまくいかないとき

| 出てきた表示 | 直し方 |
|---|---|
| `redirect_uri_mismatch` / `origin_mismatch` | 手順 4-3 の「JavaScript 生成元」が、開いているアドレスの先頭部分と同じか確かめる（`https` と `http` の違い、末尾の `/` に注意） |
| `access_denied` | 手順 3-4 のテストユーザーに、そのアカウントが入っているか確かめる |
| ポップアップがブロックされた | ブラウザのアドレスバーの右に出る表示から、このサイトのポップアップを許可する |
| 「つなぎ直す」が何度も出る | 1 時間ごとに切れるのは Google の決まりです。押すだけで再開します |
| スマホとパソコンでデータが合わない | 自分のスマホとパソコンが、自分の同じ Google アカウントでつながっているか確かめ、［今すぐ同期］を両方で押す |

## データの場所と消し方

- Google ドライブの `ラク経費`・`現場CAD` フォルダを見ると、保存されたファイルがあります。消すと、次の同期で端末から送り直されます（端末のデータは消えません）。
- 同期をやめるときは、アプリの［同期をやめる］を押します。Google アカウントの［セキュリティ → サードパーティのアクセス］からも外せます。
