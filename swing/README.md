# スイングボード

スイングトレード（数日〜数週間の売買）向けに、**相場の地合い・材料ニュース・注目銘柄**を毎日まとめるスマホ用 Web アプリです。ホーム画面に追加するとアプリとして使えます。

公開後の URL：GitHub Pages の URL の末尾に `/swing/` をつけたもの。

## 画面

| タブ | 内容 |
|---|---|
| 今日 | **ルールに合う銘柄**と、あと1つ条件が足りない銘柄、「今日は買わない日」・3連敗の休みのお知らせ、地合い（追い風／中立／向かい風）、日経平均・TOPIX・米国株・SOX・ドル円・VIX・米金利、話題のテーマと影響を受ける業種、**今日の注目銘柄**（点数・買い目安・利確目安・損切り）、材料ニュース |
| 銘柄 | 全銘柄を型（押し目／高値ブレイク／売られすぎ反発／上昇トレンド）・業種で絞り込み、点数・前日比・出来高などで並べ替え |
| ニュース | プラス／マイナス／銘柄の材料／テーマ／ウォッチ銘柄で絞り込み。見出しを押すと記事へ |
| 成績 | **これまでの注目銘柄のその後**（翌日の寄りで買い、目安どおり売ったとしての勝率・平均損益）と、**過去2年のルールの検証**（型別・点数帯別、「いつ買っても同じ」との比較） |
| 保有 | 取引記録（ルールを守れたか・集計・CSV）、マイルールの一覧。買った銘柄を登録すると、損切りライン割れ・利確到達・「損切りを買値に上げる」タイミング・売りのサイン（25日線割れ、MACD 下抜けなど）・保有期間の長さを知らせる。ウォッチ銘柄、設定 |

今日の画面には、ほかに **業種の強さランキング**、保有銘柄のお知らせ、新しく注目に入った銘柄の「新」マークも出ます。

銘柄を押すと、ローソク足チャート（25日線・75日線・出来高・利確/損切りの線）、売買の目安、**買える株数**（資金 × 許容損失% ÷ 損切り幅、100株単位）、注目する理由・注意点、**翌日の見送りライン**（これより高く寄ったら追わない）と押し目の指値案、**この銘柄での過去の成績**、関連ニュース、Yahoo!ファイナンス・株探へのリンクが出ます。

## しくみ

```
GitHub Actions（平日 7:07 と 16:37）
  └ swing/scripts/update.py … 株価（Yahoo! Finance の日足）と RSS ニュース（NHK・Yahoo!ニュース・Google ニュース・適時開示）を集める
      ├ 同じルールで過去2年を検証（バックテスト）
      ├ 注目銘柄を data/history.json に記録し、その後の成績を毎回計算
      └ swing/data/latest.json・charts.json に書き出してコミット
スマホのアプリ（swing/index.html）… その JSON を読んで表示するだけ
```

- サーバー・API キー・費用は不要です（Python の標準ライブラリだけで動きます）。
- 最初は **サンプルデータ** が入っています（画面上部に黄色の帯が出ます）。

## 使い始める

1. この変更を既定のブランチ（main）に取り込む。
2. リポジトリの **Actions** タブ → 「スイングデータ更新」 → **Run workflow** を押す（数分で終わります）。
   - 以後は平日に自動で動きます。
   - Settings → Actions → General → Workflow permissions が「Read and write」になっていないと保存に失敗します。
3. `https://<GitHub Pages の URL>/swing/` をスマホで開き、共有メニューから **ホーム画面に追加**。

### 「今すぐ更新」ボタン

アプリの上の「今すぐ更新」で、決まった時刻を待たずにデータを作り直せます（5〜10分）。

1. 「今すぐ更新」を押すと、GitHub の「スイングデータ更新」の画面が開く
2. **Run workflow** → 緑の **Run workflow** を押す
3. アプリに戻ると「自動で新しくなります」と出て待っている。新しいデータが公開されたら自動で画面が新しくなる（アプリを閉じても、次に開いたときに続きを待つ）

上級者向け：「保有」タブの設定で GitHub の合い言葉（このリポジトリだけ・**Actions: Read and write** だけの fine-grained personal access token）を登録すると、2 の手順もなくなり、ボタンだけで更新できます。合い言葉はスマホの中にだけ保存されます。

手元で試すとき：

```sh
python3 swing/scripts/update.py          # 本物のデータ（ネットが必要）
python3 swing/scripts/update.py --demo   # サンプルデータ
cd swing && python3 -m http.server 8000  # http://localhost:8000 で表示
```

## 自分の売買ルールで選ぶ

注目銘柄は、自分の売買ルール（ルール一覧.xlsx・アプリの「保有」タブの下に一覧）を**全部満たした銘柄だけ**です。銘柄の画面に、ルールごとの ✓／✗ が出ます。

| ルール | アプリでの判定 |
|---|---|
| 日経平均が下向きの時は買わない | 日経平均の25日線が5営業日前より下なら「今日は買わない日」。注目銘柄を出さない |
| 25日線が上向きで株価がその上・週足も確認 | 25日線が5営業日前より上で終値がその上。13週線（65日線）も上向きでその上 |
| 出来高が少なすぎる銘柄は避ける | 直近20日の売買代金の平均が 3億円/日 以上 |
| 急に上がった株を高値で追いかけない | 5日で +10% 未満、直近3日に +5% 以上の窓がない、25日線から +8% 未満 |
| 押し目（支持線・25日線付近）で、陽線の反発を確認して買う | 直近3日の安値が25日線（+1.2%以内）か支持線まで下がり、当日が陽線で前日比プラス |
| 支持線は2回以上跳ね返った値段 | 過去120日で「前後3日でいちばん安い日」を反発とみなし、近い値段をまとめて2回以上なら支持線（抵抗線も同じ） |
| 損切りは支持線の少し下・利確は抵抗線・利確幅は損切り幅の2倍以上 | 損切り＝株価のすぐ下の支持線の少し下。利確＝上の抵抗線の少し手前（なければ2倍）。2倍未満は買わない |
| 決算をまたがない | 3週間以内に決算発表があれば買わない。決算日が取れない銘柄は「要確認」 |
| 前日の夜に IFDOCO で仕込む | 銘柄の画面に、買い・利確・損切りの3つの値段（コピーできる） |

保有・記録のルールは「保有」タブで扱います。

- **損切りを買値まで上げる／直近安値の少し下へ上げていく**：その時期になるとお知らせし、ボタンで上げられる
- **損切りラインは絶対に下げない**：下げる入力は受けつけない
- **1回の損は資金の1〜2%まで・株数を増やさない**：設定が 2% を超えたり、計算より多い株数を入れたりすると警告。ルールに合わない買いを登録するときは確認が出て、「破った」取引になる
- **全トレードを記録・ルールを守れたかを書く**：「売った」で売値と「守れた／破った」を記録。守って勝ち・守って負け（OK）・破って勝ち（失敗）・破って負けの表、CSV 書き出し（Excel で開ける）
- **3連敗したら1週間休む**：今日の画面に休みの期限を表示し、買いの登録で確認
- **20回ごとに見直す**：20回ごとにお知らせ

### ゆるめのルール

きびしめ（上の表のとおり）だと、合う銘柄が0の日がよくあります。そこで、今日の画面・設定で **きびしめ／ゆるめ** を切り替えられます（選んだほうは覚えておきます）。

| ルール | きびしめ | ゆるめ |
|---|---|---|
| 日経平均 | 25日線が上向き | 25日線が上向き **か** 日経平均が25日線の上 |
| トレンド | 25日線が上向きで株価がその上 | ＋25日線＞75日線で株価が75日線の上（25日線の −2% まで可） |
| 週足 | 必須 | 参考（判定に使わない） |
| 押し目 | 3日以内に25日線 +1.2% まで。陽線かつ前日比プラス | 5日以内に25日線 +3% まで。陽線か前日比プラス |
| 支持線 | 2回以上の反発が必須 | 1回でよい。なければ25日線の少し下で損切り |
| 利確幅 | 損切り幅の2倍以上 | 1.5倍以上 |
| 急騰 | 5日で +10% 未満・窓 +5% 未満 | 5日で +15% 未満・窓 +7% 未満 |
| 決算 | 3週間以内なら買わない | 1週間以内なら買わない（決算の前に売る） |

- 売買代金、IFDOCO、損切りを下げない、1回の損は1〜2%、3連敗で休む、などはどちらも同じです
- 成績タブで、きびしめ・ゆるめの過去2年の検証と「注目銘柄のその後」を並べて比べられます。取引記録も、どちらのルールで買ったかを分けて集計します
- 数値は `scripts/update.py` の `RULESETS` で変えられます

点数（0〜100）は、ルールに合った銘柄どうしの順番づけに使います（出来高を伴う反発、MACD、日経平均より強いか、ニュースなど）。

## 成績・検証の計算方法

- シグナルの翌営業日の**寄り付きで買う**。寄りで損切りより下・利確より上なら見送り
- 損切り・利確に届いたらそこで売る（寄りで飛び越えたら寄り値）。同じ日に両方届いたら**損切り扱い**（厳しめ）
- 最長 15 営業日で手じまい。手数料・税金は含まない。検証はニュースを使わずテクニカルの点数だけ
- 記録を始める前の 20 営業日分は、同じルールで過去の日に選んだ銘柄を再現して表示します
- 検証は自分のルール（株価だけで判定できるもの）で行い、「日経平均の条件なし」の場合とも比べます。決算のルールは過去の決算日が取れないため使いません
- 計算のテスト：`python3 -m unittest discover -s swing/tests`

## カスタマイズ

- 対象銘柄：`scripts/universe.json`（コード・名前・業種・ニュース用の別名）
- ニュースの言葉・テーマと業種の対応：`scripts/update.py` の `POS_WORDS`・`NEG_WORDS`・`THEMES`
- 更新時刻：`.github/workflows/swing-update.yml` の `cron`（UTC）

## 注意

点数・売買の目安は、株価の動きとニュースの**見出し**から機械的に計算したものです。売買をすすめるものではありません。決算発表日・権利確定日・本文の内容はご自身で確認し、投資は自己責任で行ってください。データの取得元の仕様が変わると取得できなくなることがあります（Actions のログに「!」で表示されます）。
