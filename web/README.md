# 案件ボード（Firebase 版）

Claude を入れていない人（職人・協力会社など）も、Google アカウントでログインして使える版です。
画面と機能は Claude 版（`../app/index.html`）と同じものを使い、データ・ログイン・写真の置き場だけを Firebase に差し替えています。

## 役割

| 役割 | できること |
|---|---|
| オーナー | すべて。メンバーの役割を変えられる。最初にログインした人が自動でオーナーになる |
| 編集者 | すべて（設定・朝の報告の書き換え、承認、立替精算を含む）。社員・協力会社の役割を変えられる |
| 社員 | 設定と朝の報告の書き換え以外のすべて |
| 協力会社 | 「今日・現場・日報」だけ。写真で記録・レシートを撮る・日報を書く。経費一覧・連絡・予算は見えない |
| 承認待ち | 何も見えない。オーナー・編集者が役割を選ぶと使えるようになる |

画面上部の「メンバー管理」で、承認と役割の変更をします。

## Claude 版との違い

- AI 機能（レシート読み取り、回答案、監査、拾い出し、工事カルテ、資料仕分け、日報の下書き）は使えません。ボタンは自動で隠れます。
  レシートは写真だけが登録され、中身は経理が入力します。
- 毎朝の自動整理（朝の報告）は、まだ Claude 版のデータを見ています。Firebase 版のデータを見るようにするのは次の段階です。

## 最初の準備（一度だけ）

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作る。
2. **Authentication** → ログイン方法 → **Google** を有効にする。
3. **Firestore Database** を作る（本番モード、ロケーションは `asia-northeast1`（東京））。
4. **Storage** を始める（写真の保存先）。プロジェクトによっては従量課金プラン（Blaze）への切り替えを求められます。無料枠の範囲なら料金はかかりません。
5. プロジェクトの設定 → マイアプリ → ウェブアプリを追加し、表示される「構成」の値を `firebase-config.js` に貼る。
6. プロジェクトの設定 → サービスアカウント → 「新しい秘密鍵を生成」で JSON をダウンロードし、
   GitHub のリポジトリ → Settings → Secrets and variables → Actions に `FIREBASE_SERVICE_ACCOUNT` という名前で、その JSON の中身を丸ごと登録する。
   （この JSON は他人に渡したり、チャットに貼ったりしないでください）
7. GitHub の Actions タブ → 「Firebase に公開」 → Run workflow。
   公開先は `https://<プロジェクトID>.web.app` です。
8. 公開先を開き、**あなたが最初にログイン**する（オーナーになります）。その後で、ほかの人にURLを伝える。

## データの移行

Claude 版のデータは、JSON に書き出して「メンバー管理」→「データの取り込み」（オーナーのみ）で取り込めます。
写真は Claude 版に残るため、移行後は表示されません（必要なら撮り直してください）。

## 手元での試験

```
cd web
npm install
node build.mjs --emulator
npx firebase emulators:start --project demo-anken
# http://127.0.0.1:5000 を開き、開発者ツールで window.__testLogin("a@example.com","名前") を実行するとログインできる
```
